# 부서

**부서**는 조직 안의 팀입니다. 구성원, 관리자, 구성원 지갑을 채우는 크레딧 풀, 그리고 선택적으로
자체 자원 정책을 가집니다.

![부서](/img/screens/admin-groups.png)

조직 관리자는 자기 조직의 부서만, 부서 관리자는 자기 부서만 봅니다. **새 부서**는 이름과 조직을
묻습니다.

## 부서 관리자

![부서 관리자](/img/screens/admin-group-admins.png)

**관리자**에서 부서 구성원 중 부서 관리자를 지정합니다. 부서 관리자는 구성원을 추가·제거하고, 부서
크레딧을 개인에게 배분하고, 구성원의 크레딧 요청을 승인하고, 부서 세션을 관제할 수 있습니다.

## 구성원

구성원은 [사용자](./users.md) 페이지에서 또는 일괄로 추가합니다. 한 사용자가 여러 부서에 속할 수
있으며, 부서 맥락에서 만든 세션은 그 부서의 정책을 따릅니다.
