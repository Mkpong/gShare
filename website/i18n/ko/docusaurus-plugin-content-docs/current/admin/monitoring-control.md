# 세션에 개입하기

이 페이지의 모든 동작은 **다른 사람의 작업**에 손대는 일입니다. 각 동작은 내 이름과 함께 감사에
남고, 소유자에게 알림이 갑니다.

## 세션 하나 강제 종료

![강제 종료](/img/screens/admin-monitor.png)

행의 **강제 종료**는 소유자 동의 없이 세션을 끝냅니다.

1. 컨테이너가 중지되고 GPU가 즉시 풀로 반환됩니다.
2. 소유자가 직접 멈춘 것과 똑같이 정산됩니다. 소비분은 청구되고 예약의 나머지는 환불됩니다.
3. 소유자에게 알림이 가고, 입력한 **사유**가 세션 ID와 함께 [감사 로그](./audit.md)에 남습니다.

세션의 `status_reason`은 `admin_stopped`로 기록되고 콘솔이 소유자에게 메시지로 보여 줍니다.
"정리"가 아니라 상대가 행동할 수 있는 사유("14시 수업용으로 4090을 비워야 함")를 쓰세요.

## 일괄 정리

여러 행을 체크하면 툴바 버튼이 활성화됩니다 — **강제 종료 (N)**, **일괄 정리 (N)**. 확인 창은 끝낼
세션을 모두 이름으로 보여 주고, 다섯 개 이상이면 건수를 입력하도록 요구합니다.

남의 세션이기 때문입니다. 건수 입력은 번거로우려는 것이 아니라 실수를 불가능하게 하려는 것입니다.

## 대기열

![대기열 탭](/img/screens/admin-monitor-queue.png)

**대기열** 탭은 용량을 기다리는 세션을 순번·우선순위·대기 사유·요청 자원과 함께 보여 줍니다.

| 동작 | 효과 |
|---|---|
| **우선순위** | 항목의 우선순위 값을 정합니다(정수, 높을수록 먼저 dequeue) — 시연, 마감, 수업용 |
| *항목 제거* | 여기에는 취소 버튼이 없습니다. 세션 탭에서 대기 중인 세션을 **강제 종료**하세요. 예약은 전액 해제되고, 한 번도 돌지 않은 세션은 과금되지 않습니다 |

플릿이 꽉 찼을 때 정직한 지렛대는 우선순위입니다. 남의 실행 중 세션을 강제 종료해 대기 세션을
시작시키는 것은 다른 종류의 지렛대입니다. 알고 쓰고, 이유를 남기세요.

## 종료하기 전에: 정말 멈춘 것인가?

| 증상 | 대개는 |
|---|---|
| 세션이 오래 **대기** | 고장이 아니라 대기열입니다. 대기 사유를 확인하세요 |
| **실행 중**인데 GPU 0% | 놀고 있는 노트북. 유휴 정책이 일시정지합니다. 오히려 유휴 시간을 줄이는 것을 고려하세요 |
| 세션이 반복 재시작 | 크래시 루프 규칙이 몇 분 안에 끝냅니다 |
| 노드의 세션을 옮겨야 함 | [노드 비우기](./nodes.md#비우기) — 죽이는 대신 재배치합니다 |

비우기가 거의 항상 종료보다 낫습니다. 작업을 파괴하는 대신 옮기기 때문입니다.
