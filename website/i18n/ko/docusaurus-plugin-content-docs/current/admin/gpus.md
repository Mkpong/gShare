# GPU 디바이스

![GPU 디바이스](/img/screens/admin-gpus.png)

플릿이 보고하는 모든 카드: 노드, 클러스터, 모델 문자열, VRAM, 모드(분할·전용), 현재 점유, 바인딩된
세션, 상태. 여기 표시되는 **모델 문자열**이 [오퍼링](./resources.md#오퍼링)이 정확히 맞춰야 하는
값입니다.

## 노드별 디바이스 보기

![노드 하나의 디바이스](/img/screens/admin-node-devices.png)

[노드](./clusters.md#노드) 페이지에서 노드를 열면 그 노드의 카드를 같은 상세와 카드별 작업과 함께
나열합니다.

## 카드 고장 표시

**고장 표시**는 카드 하나를 배치에서 빼고 그 카드에 바인딩된 모든 세션을 끝냅니다(`gpu_fault`,
정산, 소유자 알림). CUDA 컨텍스트가 죽은 프로세스는 재개할 수 없으므로, 죽은 카드에 과금하는
세션보다 정직한 종료가 낫습니다. **복구**는 수리된 카드를 되돌립니다.

DCGM이 보고하는 치명적 Xid 이벤트는 노드 전체를 자동 차단합니다. 카드 작업은 여러 장 중 한 장이
나쁜 경우를 위한 것입니다.

## 별칭

카드에 **별칭**(예: `lab-4090-01`)을 붙이면 대시보드와 세션 상세가 드라이버 UUID 대신 그것을
보여 줍니다.
