# GPU 디바이스

플릿이 보고하는 모든 카드와 지금 그 위에 있는 것.

![GPU 디바이스](/img/screens/admin-gpus.png)

| 열 | 의미 |
|---|---|
| **노드 / 클러스터** | 카드의 위치 |
| **모델** | 드라이버의 정확한 문자열. [오퍼링](./resources-offerings.md)이 맞춰야 하는 값입니다 |
| **별칭** | 카드에 붙인 사람이 읽는 이름 |
| **VRAM (사용/전체) · 코어** | 실시간 사용률이 아니라 할당량입니다 |
| **모드** | 분할 또는 전용 |
| **바인딩 세션** | 이 카드의 조각을 쥔 세션 |
| **목표 풀** | 옮겨 가는 중인 [풀](./node-pools.md) |
| **장애 관리** | 장애 표시 / 복구 |

노드별 카드 화면은 [노드](./nodes.md)에서 들어갑니다.

![노드 하나의 카드](/img/screens/admin-node-devices.png)

## 카드에 이름 붙이기

![이름 지정](/img/screens/admin-gpu-alias.png)

**별칭**(`lab-4090-01`, `rack3-slot2`)은 카드가 나타나는 모든 곳 — 대시보드 타일, 세션 상세, 관제 —
에서 모델명+순번 라벨을 대체합니다. 클러스터 안에서 고유해야 하고 32자 이내이며, 비우면 생성된
이름으로 돌아갑니다.

기계에 붙은 스티커와 같은 별칭을 주세요. 사용자가 "세션의 GPU가 느려요"라고 할 때, 별칭이 있으면
그것이 UUID가 아니라 위치가 됩니다.

## 카드 모드 바꾸기

카드는 한 가지 모드로 돕니다 — **분할**(HAMi 조각), **전용**(카드 전체), 하드웨어가 지원하면
**MIG** — 그리고 행에서 카드별로 바꿀 수 있습니다. 변경은 **예약**됩니다. 카드가 새 세션을 받지
않다가 현재 세션이 모두 빠지면 전환되므로 실행 중인 것은 방해받지 않습니다. 전환 대기 중이면 모드
열에 *현재 → 목표*로 표시됩니다.

## 카드를 장애로 표시

![장애 표시](/img/screens/admin-gpu-fault.png)

**장애 표시**는 카드 하나를 배치에서 빼고 **그 카드에 묶인 모든 세션을 종료**합니다(`gpu_fault`).
각각 정산되고 소유자에게 알림이 갑니다. 의도된 동작입니다. CUDA 컨텍스트가 죽은 프로세스는 재개할
수 없고, 죽은 카드에 조용히 과금하는 세션보다 정직한 종료가 낫습니다.

**복구**는 수리된 카드를 배치에 되돌립니다.

DCGM이 보고하는 치명적 Xid 이벤트는 **노드 전체**를 자동 차단합니다. 카드 동작은 더 좁은 경우를
위한 것입니다. 여러 장 중 한 장만 나쁘고 나머지 기계는 멀쩡할 때.

## 할당은 사용률이 아닙니다

여기의 VRAM 수치는 원장이 **예약**한 양입니다. 카드가 실제로 무엇을 하는지는
[모니터링 페이지](./platform-monitoring.md)의 DCGM에서 옵니다. 90% 할당에 15% 사용인 플릿은
하드웨어가 부족한 것이 아니라 유휴 시간과 더 작은 [티어](./resources-presets.md)가 부족한 것입니다.
