# 정산 리포트

플랫폼 관리자의 **크레딧 관리 → 정산 리포트** 메뉴는 회계 및 감사 관점에서 설정된 기간 동안 테넌트별로 **실제 소비된 크레딧과 자원 사용량**을 집계합니다. 단순한 실시간 잔액 조회를 넘어, 지정된 조회 기간 내의 실제 자원 소모 현황을 분석할 수 있습니다.

![정산 리포트 화면](/img/screens/admin-credits-settlement.png)

---

## 정산 리포트 조회 조건

1. **기간 설정**: 조회 시작일과 종료일을 지정합니다. (두 항목 모두 지정해야 조회가 실행됩니다.)
2. **조회 범위 (Scope)**: 플랫폼 전체, 특정 조직, 또는 특정 부서 단위로 제한할 수 있습니다.
3. **집계 기준**:
   * **오퍼링 (Offering)**: 소모된 크레딧이 어느 GPU 카탈로그/모델에 사용되었는지 기준으로 집계
   * **지갑 (Wallet)**: 크레딧이 차감된 대상 사용자 계정, 부서 지갑, 크레딧 풀 기준으로 집계
4. **조회 실행**: 설정한 필터 조건에 따라 리포트를 생성합니다.

| 테이블 항목 | 의미 및 설명 |
|---|---|
| **그룹** | 집계 대상 개체 (조직, 부서, 오퍼링 모델, 지갑 등) |
| **소모** | 지정된 기간 동안 실제 서비스 이용으로 차감/청구된 크레딧 수량 |
| **충전** | 지정된 기간 동안 해당 범위에 새로 발행 및 배분된 크레딧 수량 |
| **GPU 시간** | 소모된 크레딧의 기반이 되는 실제 물리적 GPU 카드 가동 시간 |

> **데이터 일관성**: 정산 리포트의 모든 집계 수치는 시스템 원장(Ledger) 데이터를 기반으로 산출되므로, 사용자가 개인 **[거래 내역](../user/wallet-ledger.md)**에서 확인하는 내역과 정확히 일치합니다.

---

## 주요 활용 및 분석 항목

* **크레딧 실사용률 분석**: **[배분된 크레딧 양](./credits-allocate.md)**과 *실제 소모량*을 비교하여, 각 조직·부서가 할당받은 예산을 실제로 효율적으로 사용하고 있는지 파악할 수 있습니다.
* **자원 유형별 비용 추적**: 오퍼링 단위로 집계 시, 배정된 크레딧이 목적에 맞는 GPU 모델 및 워크로드에 소비되었는지 검토할 수 있습니다.
* **차기 예산 및 배분 계획**: 단순 신청량이 아닌 *실제 사용된 GPU 시간*을 바탕으로 다음 기수/월의 크레딧 배분 규모를 정밀하게 산정할 수 있습니다.

> **행위 단위 추적**: 배분, 승인, 회수 등 개별 관리자의 작업 행위 이력을 추적하거나 CSV 파일로 내보내려면 **[감사 로그](./audit.md)** 메뉴를 이용하세요.
