# 정산 리포트

**크레딧 관리 → 정산 리포트**(플랫폼 관리자)는 회계 관점의 화면입니다. 다른 탭이 보여 주는 순간
잔액이 아니라, 기간 동안 **실제로 소비된 양**을 테넌트별로 집계합니다.

![정산 리포트](/img/screens/admin-credits-settlement.png)

## 조회하기

1. **기간** — 시작과 끝. 둘 다 없으면 조회되지 않습니다.
2. **스코프** — 플랫폼 전체, 조직 하나, 또는 부서 하나.
3. **집계 기준** — **오퍼링**(크레딧이 어느 GPU 모델로 갔는지) 또는 **지갑**(어느 사람·풀인지).
4. **조회**.

| 열 | 의미 |
|---|---|
| **그룹** | 행이 집계하는 조직·부서·오퍼링·지갑 |
| **소모** | 기간 동안 실제로 청구된 크레딧 |
| **충전** | 기간 동안 그 범위에 발행된 크레딧 |
| **GPU 시간** | 소모 뒤의 카드 시간 — 크레딧이 산 물리적인 양 |

수치는 모든 지갑과 같은 원장에서 나오므로, 사용자가 자기 [거래 내역](../user/wallet-ledger.md)에서
보는 것과 정확히 일치합니다.

## 답해 주는 것

- **어느 조직·부서가 받은 크레딧을 실제로 썼는지**, 어디가 받아만 두고 쓰지 않았는지 — *소모*를
  [배분한 양](./credits-allocate.md)과 비교하세요.
- **크레딧이 무엇을 샀는지**: 오퍼링 기준으로 집계하면 기대한 카드에 쓰였는지 보입니다.
- 테넌트별 **GPU 시간당 비용**. 요청받은 양이 아니라 실제로 쓴 양으로 다음 기간 배분을 정할 때.

누가 배분했고 누가 승인했고 누가 회수했는지 같은 **행위 단위** 추적은 CSV로 내보낼 수 있는
[감사 로그](./audit.md)를 쓰세요.
