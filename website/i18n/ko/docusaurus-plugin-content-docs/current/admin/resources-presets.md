# 프리셋 관리 (Presets)

**프리셋(Preset)**은 사용자가 세션을 생성할 때 손쉽게 선택할 수 있도록 연산 자원의 스펙(CPU, 메모리, GPU 비율 등)을 표준화하여 정의한 사전 설정 규격입니다. 사용자는 세션 생성 마법사에서 복잡한 자원 수치를 직접 계산하지 않고 정의된 프리셋을 빠르게 선택할 수 있습니다.

![프리셋 목록 화면](/img/screens/admin-presets.png)

## 프리셋 카탈로그 유형

프리셋 카탈로그는 역할에 따라 **컴퓨트 프리셋**과 **GPU 티어** 두 가지 종류로 구분됩니다.

| 프리셋 종류 | 정의 및 설정 항목 |
|---|---|
| **컴퓨트 프리셋 (Compute Preset)** | CPU 코어 수, 시스템 메모리 용량, 임시 디스크(Ephemeral Disk) 크기 (예: *Compute S / M / L / XL*) |
| **GPU 티어 (GPU Tier)** | 단일 GPU 카드 내 자원 점유 비율 (예: *XL 1/2, L 1/4, M 1/8, S 1/16*, 또는 *전용(1/1)*) |

> **GPU 티어 동적 계산 방식**: GPU 티어의 VRAM 및 코어 할당 비율은 사용자가 선택한 **[GPU 오퍼링](./resources-offerings.md)**의 전체 자원량을 기준으로 동적 계산됩니다. 따라서 단일 티어 설정 하나로 플랫폼 내 모든 GPU 카드 모델에 공통 적용할 수 있습니다. (예: *XL* 티어 선택 시 사용자가 선택한 GPU 모델과 관계없이 해당 카드의 50% 자원을 할당)

## 신규 프리셋 생성

![신규 프리셋 생성 대화 상자](/img/screens/admin-preset-new.png)

프리셋 생성 시 한눈에 이해할 수 있는 직관적인 명칭을 부여하고 해당 자원 규격을 지정합니다.

* **카탈로그 최적화 권장**: 사용자에게 과도하게 많은 프리셋 옵션을 제공하기보다 선택지를 명확히 단순화하는 것이 좋습니다. 컴퓨트 프리셋 5개, GPU 티어 5개 내외로 목록을 구성하면 대부분의 워크로드를 충분히 수용할 수 있습니다.

## 운영 효율을 높이는 크기 설정 가이드

* **배포 이미지 크기에 맞춘 임시 디스크 할당**: 15GiB 용량의 CUDA 딥러닝 이미지를 사용하는 환경에 20GiB 디스크만 할당할 경우, 데이터 세트 로드 및 작업 진행 중 공간 부족(`No space left on device`) 오류가 발생합니다. 베이스 이미지 크기를 고려하여 데이터 작업이 가능한 충분한 여유 공간을 확보하도록 프리셋 디스크를 설정하세요.
* **소형 GPU 티어(1/16 등) 상시 유지**: 클러스터 자원 점유율이 높을 때도 소형 조각 티어 워크로드는 대기 없이 즉시 스케줄링 배치될 가능성이 높습니다. 소형 티어를 유지하면 자원 고갈 시 사용자 대기 상태 문의를 크게 줄일 수 있습니다.
* **전용 모드 노드 부재 시 전용 티어 비활성화**: 물리 플릿 내 전용(Exclusive) 모드로 동작하는 노드가 없는 경우, 세션 생성 마법사에서 전용 티어를 제공하지 마세요. 선택 불가 상태로 노출되면 사용자가 시스템 장애로 오인할 수 있습니다.

## 커스텀 자원 설정 (Custom Size)

프리셋 표준 규격으로 수용할 수 없는 특수 워크로드의 경우, 사용자는 세션 생성 마법사에서 **커스텀(Custom)** 옵션을 열어 VRAM 및 GPU 코어 할당량을 직접 수동 지정할 수 있습니다. (단, 설정된 **[자원 정책](./resources-policies.md)** 한도 내에서만 허용)

> **프리셋 개선 팁**: 프리셋은 빠른 선택을 돕는 가이드라인입니다. 다수의 사용자가 특정 수치로 커스텀 설정을 반복하여 사용하고 있다면, 해당 수치를 새로운 표준 프리셋으로 추가 등록하는 것을 권장합니다.
