# 프리셋

**프리셋**은 미리 만들어 둔 세션 크기입니다. 사용자는 마법사에서 프리셋을 먼저 고르고, 뒤의 숫자는
보이지 않습니다.

![프리셋](/img/screens/admin-presets.png)

같은 카탈로그에 두 종류가 있습니다.

| 종류 | 정하는 것 |
|---|---|
| **컴퓨트 프리셋** | CPU 코어, 메모리, 임시 디스크 — 시드 카탈로그의 *Compute S/M/L/XL* |
| **GPU 티어** | 카드의 몇 분의 몇: XL ½, L ¼, M ⅛, S 1/16, 또는 전용 |

티어의 VRAM과 코어는 선택된 오퍼링의 카드 전체 값에서 계산되므로, 티어 하나가 모든 모델에서
동작합니다. *XL*은 사용자가 고른 카드가 무엇이든 그것의 절반입니다.

## 만들기

![새 프리셋](/img/screens/admin-preset-new.png)

한눈에 이해되는 이름을 주고 컴퓨트 형태나 비율을 정합니다. 목록은 짧게 유지하세요. 컴퓨트 다섯,
티어 다섯이면 거의 모든 경우를 덮고, 목록이 길면 선택이 아니라 결정 과제가 됩니다.

## 문의를 줄이는 크기 설정

- **임시 디스크를 배포 이미지에 맞추세요.** 15 GiB CUDA 이미지에 20 GiB 디스크를 주면 데이터가 들어갈
  자리가 거의 없고, 그 실패("no space left")는 프리셋을 가리키지 않습니다.
- **작은 티어를 항상 하나는 남겨 두세요.** "클러스터가 꽉 찼다"에 대한 답입니다. 1/16 조각은 대개
  즉시 시작됩니다.
- **전용 모드 노드가 없으면 전용 티어를 제공하지 마세요.** 마법사에 사용 불가로만 표시되어 고장처럼
  보입니다.

## 프리셋이 못 맞추는 경우를 위한 커스텀

사용자는 언제든 마법사의 **커스텀**을 열어 VRAM과 코어를 직접 지정할 수 있습니다(정책 한도 안에서).
프리셋은 빠른 길이지 울타리가 아닙니다. 모두가 같은 숫자로 커스텀을 쓰고 있다면, 그것은 아직 만들지
않은 프리셋입니다.
