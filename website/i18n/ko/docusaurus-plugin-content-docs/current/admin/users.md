# 사용자

![사용자](/img/screens/admin-users.png)

내 범위의 모든 사용자를 상태, 소속, 역할과 함께 나열합니다. 이름이나 이메일로 검색하고, 행을 열어
표시 이름 수정, 비밀번호 초기화(다음 로그인 때 새 비밀번호 강제), 소속 변경, 계정 비활성화를 합니다.
비활성화된 사용자는 즉시 로그아웃되고 다시 활성화될 때까지 로그인할 수 없습니다.

## 사용자 추가

**새 사용자**는 이메일, 표시 이름, 초기 비밀번호, 부서 소속으로 계정 하나를 만듭니다. 사용자는 첫
로그인 때 비밀번호를 바꿔야 합니다.

## 일괄 등록

![일괄 등록](/img/screens/admin-users-bulk.png)

**일괄**은 `email,name,group,role` 형식의 CSV를 받아 계정을 한 번에 만들고, 행마다 생성됨·이미
있음·거부됨을 보고합니다. 수업이나 새 팀을 온보딩할 때 쓰세요.

## 삭제

사용자 삭제는 이메일 입력을 요구합니다. 그 사용자의 세션은 종료·정산되고, 개인 볼륨은 사이트의
유예 기간 후 회수되도록 예약되며, 감사 이력은 유지됩니다.
