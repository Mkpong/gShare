# 조직

**조직**은 테넌시 트리의 꼭대기입니다. 조직이 부서를, 부서가 사용자를 소유하고, 크레딧은 같은 트리를
따라 내려갑니다. 조직은 시스템 관리자가 만듭니다.

![조직](/img/screens/admin-orgs.png)

목록은 각 조직의 부서 수와 사용자 수를 보여 줍니다. **새 조직**은 이름만 필요합니다. 삭제는 이름
입력을 요구하며, 실행 중인 세션이 있는 조직은 삭제할 수 없습니다.

## 조직 관리자

![조직 관리자](/img/screens/admin-org-admins.png)

**관리자**에서 조직 사용자 중 조직 관리자를 지정합니다. 조직 관리자는 조직의 모든 부서와 사용자를
관리하고, 조직의 크레딧을 부서에 배분하며, 조직의 세션과 감사 항목을 봅니다 — 그 밖은 아무것도
보지 못합니다.

## 예산

조직은 **예산**을 가질 수 있습니다. 한 기간 동안 구성원이 소비할 수 있는 크레딧의 상한입니다. 세션
승인은 개인 지갑 다음에 예산을 검사하므로, 몫을 다 쓴 부서는 개별 지갑에 크레딧이 남아 있어도
거부됩니다.
