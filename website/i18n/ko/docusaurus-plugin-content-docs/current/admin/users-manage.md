# 계정 관리

![사용자 편집](/img/screens/admin-user-edit.png)

**계정 편집** 기능을 통해 관리자는 계정의 속성 및 권한 상세 정보를 변경할 수 있습니다.

## 편집 창에서 변경 가능한 항목

| 관리자 역할 | 변경 가능 항목 |
|---|---|
| **시스템 관리자** | 이메일, 이름, 조직, 부서, 비밀번호 |
| **조직 관리자** | 부서 (소속 조직 내 부서로 변경 가능), 비밀번호 |
| **부서 관리자** | 비밀번호 |

계정에 부서를 추가하면 해당 부서의 크레딧 및 자원 정책이 함께 적용되며, 부서를 제거하면 해당 권한이 해제됩니다. 이미 실행 중인 세션은 종료될 때까지 기존 설정에 영향을 받지 않습니다.

**사용자의 관리자 역할(Role)은 계정 편집 창에서 설정하지 않습니다.** 부서 및 조직 관리자 역할은 [부서](./groups.md#부서-관리자-group-admin) 및 [조직](./organizations.md#조직-관리자-organization-admin) 관리 페이지에서 지정할 수 있으며, 자신이 보유한 역할 이하의 권한만 부여할 수 있습니다. 전역 역할인 시스템 관리자 권한은 시스템 관리자가 API를 통해 직접 지정해야 하며, 콘솔 UI에서는 별도의 설정 컨트롤을 제공하지 않습니다.

계정 편집 창에서는 해당 계정의 **사용 현황**(실행 중인 세션, 점유 중인 GPU/호스트 자원, 볼륨, 크레딧 지갑)을 함께 제공하므로, 계정 비활성화나 삭제 시 영향을 받는 자원을 사전에 확인할 수 있습니다.

모든 변경 내역은 변경 전/후 값과 함께 [감사 로그](./audit.md)에 상세히 기록됩니다.

## 비밀번호 초기화

계정 편집 창에서 새 비밀번호를 설정하면, 해당 사용자는 다음 로그인 시 비밀번호를 의무적으로 변경해야 합니다. 보안을 위해 기존 비밀번호는 암호화 해시 상태로 저장되며 시스템 관리자를 포함하여 누구도 조회할 수 없습니다.

생성된 임시 비밀번호는 안전한 보안 채널을 통해 전달하고, 일회성 무작위 단어를 사용하는 것을 권장합니다. 임시 비밀번호 역시 변경되기 전까지는 인증 자격 증명으로 기능하므로 관리에 주의가 필요합니다.

## 비활성화

**계정 비활성화** 처리 시 해당 사용자는 즉시 강제 로그아웃되며 이후 시스템 접근이 차단됩니다. 단, 기존에 실행 중이던 세션은 강제 종료되지 않습니다 (GPU 자원을 정리해야 하는 경우 [세션 관제](./monitoring-control.md) 메뉴에서 세션을 수동 종료하세요). 사용자의 볼륨 및 크레딧 데이터는 보존되며, 필요 시 언제든지 계정을 다시 활성화할 수 있습니다.

일시적인 부재/휴직 사용자나 계정 도용이 의심되는 경우 비활성화 기능을 활용하세요.

## 삭제

계정 삭제는 복구가 불가능한 작업이므로, 확인을 위해 대상 사용자의 이메일 주소를 명확히 입력해야 합니다.

콘솔에서 수행하는 계정 삭제 동작 방식(*소프트 삭제*)은 다음과 같습니다.

1. 실행 중인 모든 세션이 관리자 강제 종료 절차에 따라 종료 및 정산 처리됩니다.
2. 계정이 비활성화 상태로 전환되며 삭제 상태로 표시됩니다. (로그인 불가 및 사용자 목록 제외)
3. **소유했던 볼륨, 크레딧 지갑, 작업 이력은 보존됩니다.** 삭제 후 필요 시 [스토리지](./storage.md) 메뉴에서 볼륨을 타 사용자에게 이관하거나 삭제하고, 미사용 크레딧은 크레딧 풀로 수동 회수해야 합니다.
4. 해당 사용자가 수행한 제반 감사 로그(Audit Log) 이력은 삭제되지 않고 안전하게 보존됩니다.

완전한 영구 삭제(*하드 삭제*) 기능은 시스템 관리자 전용 API를 통해서만 제공되며, 생성된 세션 이력이 전혀 없는 계정에 한해 실행할 수 있습니다. 하드 삭제 시 계정 소속, 공유 권한, 크레딧 지갑 데이터가 시스템에서 완전히 제거됩니다.

:::caution 계정 삭제 전 비활성화 권장
퇴사 또는 인사이동 사용자의 경우 계정 삭제보다는 **비활성화** 처리를 권장합니다. 즉시 시스템 접근이 차단되는 한편, 해당 사용자가 보유했던 자원이나 데이터 중 팀에 필요한 항목이 있는지 점검하고 이관할 수 있는 유예 기간을 확보할 수 있습니다.
:::
