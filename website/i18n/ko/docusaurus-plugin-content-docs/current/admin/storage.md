# 스토리지 풀과 볼륨

**자원 → 볼륨 관리**(시스템 관리자)는 두 가지를 다룹니다. 사용자 볼륨을 받치는 **풀**, 그리고
**볼륨** 자체.

![볼륨](/img/screens/admin-volumes.png)

## 스토리지 풀

**풀**은 스토리지 서버 하나를 객체로 등록한 것입니다. 소속 클러스터, 거기서 프로비저닝하는
StorageClass, 공유 범위 — 플릿의 **모든** 클러스터 또는 **선택한** 클러스터. 대시보드의 스토리지
타일과 새 볼륨을 승인하는 용량 게이트 모두 등록된 풀을 읽습니다.

풀의 **용량**은 다음 순서로 정해집니다.

1. **csi** — 드라이버 자신의 `GetCapacity`. `CSIStorageCapacity` 객체로 발행되고 오퍼레이터가
   읽습니다. 유일한 자동 소스.
2. **manual** — 풀에 적어 둔 값. 드라이버가 용량을 발행하지 않을 때 설정합니다.
3. **node disk** — 스토리지 노드의 시스템 디스크. 대용으로 표시됩니다.

서버가 여러 대면 풀도 여러 개입니다. 볼륨은 정확히 하나에 존재하므로 대시보드가 보여 주는 상한은
합계가 아니라 사용 가능한 풀 중 **가장 큰** 것입니다. 운영자용 상세는
[운영 → 스토리지](../operations/storage.md)에 있습니다.

## 볼륨

볼륨 목록은 플릿의 모든 볼륨을 소유자, 쿼터, 저장량, 고정된 클러스터, 마운트 중인 세션 여부와 함께
보여 줍니다. 관리자는 쿼터를 올리거나, 잠그거나, 삭제(이름 입력)할 수 있습니다. 삭제된 볼륨은
차트의 유예 기간(`api.volumeReclaimGraceHours`) 후 회수됩니다.

볼륨은 사용자에게 **무료**입니다. 조절 수단은 [자원 정책](./resources.md#자원-정책)의 볼륨 쿼터입니다.
