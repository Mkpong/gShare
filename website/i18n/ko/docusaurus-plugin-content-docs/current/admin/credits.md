# 크레딧 배분

크레딧은 **계층을 따라 아래로** 배분됩니다 — 플랫폼 → 조직 → 부서 → 사용자. 어느 단계도 받은 것보다
많이 나눠 줄 수 없습니다.

![크레딧 배분](/img/screens/admin-allocations.png)

- **시스템 관리자**는 조직 풀을 충전합니다.
- **조직 관리자**는 조직에서 부서로 배분합니다.
- **부서 관리자**는 부서 풀에서 구성원 개인에게 — 한 명씩 또는 **전원에게** 한 번에 — 배분하고,
  쓰지 않은 크레딧을 회수할 수 있습니다.

![부서 관리자 화면](/img/screens/admin-allocations-group.png)

## 월 리필

사용자마다(또는 부서 전원에게) **월 리필**을 둘 수 있습니다. 매달 초 부서 풀에서 그 금액까지 지갑이
채워집니다. 매달 같은 금액을 손으로 나눠 주는 일을 대신합니다.

## 요청

**요청 관리** 탭은 구성원의 크레딧 요청을 금액과 사유와 함께 나열합니다. 승인하면 내 풀에서
구성원 지갑으로 크레딧이 이동하고 알림이 가며, 반려하면 요청자에게 보이는 사유를 묻습니다.

## 무엇이 과금되나

지갑은 **GPU 세션 시간에만** 과금됩니다. 단가 × 점유율 × 실행 시간, 시작 시 예약과 종료 시 미사용분
환불. CPU 세션과 볼륨은 비용이 없고 대신 [자원 정책](./resources.md)으로 제한됩니다. 모든 이동은
[감사 로그](./audit.md)와 사용자의 지갑 이력 양쪽에 원장 행으로 남습니다.
