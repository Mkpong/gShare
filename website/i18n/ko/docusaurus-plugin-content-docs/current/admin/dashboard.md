# 관리자 대시보드

관리자 대시보드는 내 범위 안에서 무엇이 돌고 있는지 요약합니다.

## 조직·부서 관리자로 볼 때

![조직 범위 대시보드](/img/screens/admin-dashboard.png)

수치는 **내가 관리하는 사람들** — 내 부서의 모든 구성원(조직 관리자라면 조직의 모든 부서) — 에
대해 합산되며, 다른 테넌트는 절대 포함되지 않습니다. 실행·활성 세션, 그들이 쥔 VRAM, 호스트 CPU.
아래 패널은 세션 자체와 내 범위의 최근 감사 항목을 나열합니다.

## 플랫폼 관리자로 볼 때

![플랫폼 범위 대시보드](/img/screens/admin-dashboard-platform.png)

시스템 관리자는 전체 플릿을 봅니다.

- **활성 세션, 대기열, GPU 사용률, VRAM 적재율, 빈 GPU**, 최근 24시간 크레딧 소모.
- **GPU 디바이스** — 카드마다 타일 하나. 클러스터 태그, 모드(분할·전용), VRAM 적재, 여유 코어.
- **노드 상태** — 사용 중, 정상, 차단, 오프라인, 열린 헬스 경보.
- **호스트 자원** — 플릿 전체의 CPU, 메모리, 디스크.
- **스토리지 서버** — 등록된 [스토리지 풀](./storage.md), 소속 클러스터, 클러스터 간 공유 여부,
  용량 대비 프로비저닝된 볼륨 쿼터.
- **최근 활동** — 최신 감사 항목.

상단 바의 **클러스터 선택**으로 모든 수치를 한 클러스터로 좁힐 수 있습니다. 스토리지 패널은 풀이
플릿 전체에 공유되어 어느 한 클러스터의 것이 아닐 때 그렇다고 표시합니다.
