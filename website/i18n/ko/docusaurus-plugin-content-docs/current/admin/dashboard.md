# 관리자 대시보드

관리자 콘솔의 첫 화면은 **내 범위 안에서** 무엇이 돌고 있는지 요약합니다.

## 조직·부서 관리자로 볼 때

![조직 범위 대시보드](/img/screens/admin-dashboard.png)

타일 네 개가 **내가 관리하는 사람들** — 내 부서의 구성원 전원, 조직 관리자라면 조직의 모든 부서 —
기준으로 합산되며 다른 테넌트는 절대 포함되지 않습니다. **실행 중 세션**, **활성 세션**, 그
세션들이 쥔 **VRAM**, 플릿 대비 차지한 **CPU**. 세션 자체는 [관제](./monitoring.md)에, 크레딧은
[배분 페이지](./credits-allocate.md)에 있습니다.

클러스터 전역 수치 — 플릿 가동률, 노드 상태, 스토리지 — 는 의도적으로 시스템 관리자 전용입니다.
테넌트 관리자는 기계가 아니라 사람을 관리합니다.

## 플랫폼 관리자로 볼 때

![플랫폼 범위 대시보드](/img/screens/admin-dashboard-platform.png)

| 패널 | 답해 주는 것 |
|---|---|
| **활성 세션 · 대기열** | 기다리는 것이 있는지, 얼마나 돌고 있는지 |
| **GPU 사용률 · VRAM 적재율** | 할당 대비 실사용. 90% 할당에 20% 사용이면 용량 문제가 아니라 정책 문제입니다 |
| **빈 GPU** | 지금 아무것도 올라가 있지 않은 카드 |
| **최근 24h 크레딧** | 플랫폼 전체 소비 속도와 활성 예약 |
| **GPU 디바이스** | 카드마다 타일 하나: 클러스터 태그, 모드, VRAM 적재, 여유 코어 |
| **노드 상태** | 사용 중, 정상, 차단, 오프라인, 열린 헬스 경보 |
| **호스트 자원** | 플릿 전체의 CPU·메모리·디스크 |
| **스토리지 서버** | 등록된 [풀](./storage.md) 전체 용량 합계 대비 프로비저닝된 볼륨 쿼터, 그 아래 풀마다 자기 사용량·소속 클러스터·공유 여부 |
| **최근 활동** | 플릿 전체의 최신 감사 항목 |

상단 바의 **클러스터 선택**으로 모든 수치를 한 클러스터로 좁힐 수 있습니다. 풀이 어느 한 클러스터의
것이 아니면 스토리지 패널이 *클러스터 간 공유*라고 표시합니다.

## 다음으로

대시보드는 출발점이지 조작판이 아닙니다. 실제로 *하는* 일은 한 번의 클릭 너머에 있습니다. 지금 무엇이
도는지는 [세션 관제](./monitoring.md), 누가 얼마를 쓸 수 있는지는 [크레딧](./credits.md), 기계는
[노드](./nodes.md).
