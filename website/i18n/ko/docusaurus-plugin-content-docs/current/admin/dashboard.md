# 관리자 대시보드

관리자 콘솔의 대시보드는 로그인한 관리자의 권한 범위(Scope) 내에서 현재 구동 중인 세션, 자원 점유 현황 및 인프라 상태를 한눈에 파악할 수 있는 통합 요약 화면입니다.

---

## 조직 및 부서 관리자 관점 (Organization / Group Admin)

![조직 범위 대시보드](/img/screens/admin-dashboard.png)

대시보드 상단의 지표 타일은 **관리자 본인의 관할 테넌트 범위 내 데이터만 합산**하여 제공하며, 타 테넌트의 정보는 격리되어 표시되지 않습니다. (부서 관리자의 경우 해당 부서 구성원 전체, 조직 관리자의 경우 소속된 모든 부서 기준)

* **주요 요약 타일**: **실행 중인 세션 수**, **활성 세션 수**, **점유 VRAM 용량**, **플릿 대비 CPU 점유율**
* **관련 메뉴 연결**: 상세 세션 현황은 **[세션 관제](./monitoring.md)**, 크레딧 배분 현황은 **[크레딧 배분](./credits-allocate.md)** 메뉴에서 관리할 수 있습니다.

> **테넌트 관리자 권한 범위**: 클러스터 전역 인프라 수치(전체 플릿 가동률, 노드 상태, 스토리지 풀 등)는 시스템 관리자 전용 정보입니다. 테넌트 관리자는 하드웨어 인프라가 아닌 소속 테넌트의 사용자 및 자원 점유 관리에 집중할 수 있도록 UI가 구성되어 있습니다.

## 플랫폼 시스템 관리자 관점 (Platform Admin)

![플랫폼 범위 대시보드](/img/screens/admin-dashboard-platform.png)

플랫폼 시스템 관리자 대시보드에서는 데이터 플레인 클러스터 전체 플릿의 상태와 자원 사용 현황을 통합 모니터링할 수 있습니다.

| 주요 패널 | 모니터링 항목 및 의미 |
|---|---|
| **활성 세션 및 대기열** | 현재 실행 중인 세션 수 및 대기(Pending) 상태의 세션 수 |
| **GPU 사용률 및 VRAM 적재율** | 할당된 자원 대비 실제 GPU/VRAM 사용률 (자원 할당률 대비 실사용률이 현저히 낮을 경우 자원 회수 정책 점검 필요) |
| **빈 GPU (Idle GPUs)** | 현재 워크로드가 할당되어 있지 않은 유휴 GPU 디바이스 카드 현황 |
| **최근 24시간 크레딧** | 최근 24시간 동안의 플랫폼 전체 크레딧 소모 속도 및 활성 예약 금액 |
| **GPU 디바이스** | 카탈로그 카드별 타일 제공: 클러스터 태그, 실행 모드, VRAM 적재량, 여유 코어 비율 |
| **노드 상태** | 노드별 상태 구분: 사용 중, 정상, 차단(Cordon), 오프라인 및 헬스 체크 경보 현황 |
| **호스트 자원** | 클러스터 전체 플릿의 물리 CPU, 메모리, 시스템 디스크 사용률 |
| **스토리지 서버** | 등록된 **[스토리지 풀](./storage.md)** 전체 용량 대비 프로비저닝된 볼륨 쿼터, 풀별 사용량, 소속 클러스터 및 공유 여부 |
| **최근 활동 (Audit Activity)** | 플랫폼 전체에서 발생한 최근 감사 로그 및 변경 이벤트 |

* **클러스터 필터링**: 대시보드 상단 바의 **클러스터 선택** 드롭다운을 통해 특정 데이터 플레인 클러스터 단위로 모든 수치를 축소하여 모니터링할 수 있습니다. 특정 클러스터 전용이 아닌 스토리지 풀은 *'클러스터 간 공유'*로 표시됩니다.

## 주요 기능 메뉴 안내

대시보드는 인프라 및 테넌트 현황을 파악하는 모니터링 출발점입니다. 세부 조작 및 관리는 다음 개별 메뉴에서 실행합니다.

* **실시간 세션 동작 모니터링**: **[세션 관제](./monitoring.md)**
* **테넌트 및 사용자별 크레딧 관리**: **[크레딧 관리](./credits.md)**
* **물리 노드 및 인프라 제어**: **[노드 관리](./nodes.md)**
