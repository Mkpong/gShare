# 감사 로그

![감사 로그](/img/screens/admin-audit-platform.png)

권한, 과금, 세션, 자원의 모든 변경이 불변 감사 로그에 기록됩니다. 누가, 무엇을, 어느 대상에, 결과,
그리고 전후 상세. 조직 관리자는 자기 조직의 항목을, 부서 관리자는 자기 부서의 항목을, 시스템
관리자는 전부를 봅니다.

## 필터

**행위자**(이름 또는 이메일), **액션**, **결과**, **대상 ID**, **기간**으로 필터합니다. 필터는
주소창의 일부이므로 티켓에 붙여 넣은 쿼리가 같은 행을 재현합니다. 항목을 열면 전체 상세와 인용할
식별자가 나옵니다.

## 내보내기

**CSV 내보내기**는 현재 보기 — 같은 범위와 필터로 모든 페이지 — 를 Excel이 바로 여는 UTF-8(BOM)
파일로 내려받습니다. 내보내기 자체도 기록됩니다(`audit.export`, 필터와 행 수 포함). 시스템 밖으로
나가는 파일도 다른 작업만큼 추적됩니다.

## 기록되는 것

로그인과 실패, 비밀번호 변경, 역할·소속 변경, 모든 크레딧 이동, 세션 생성·일시정지·재개·종료(누가
강제했고 왜인지 포함), 볼륨 생성·공유·삭제, 오퍼링·정책 수정, 노드 차단·비우기·삭제, 클러스터 등록,
브랜딩 변경, 접근 거부(`access.denied`, 분당 중복 제거).

보존 기간은 차트에서 설정합니다(`api.auditRetentionDays`, 기본 180일).
