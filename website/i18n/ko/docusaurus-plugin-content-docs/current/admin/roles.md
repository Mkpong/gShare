# 역할과 범위

gShare는 단일 콘솔에서 두 가지 모드를 제공합니다. 관리자 권한을 보유한 사용자는 우측 상단의 **관리자 콘솔** 버튼을 통해 모드를 전환할 수 있으며, 부여된 역할(권한) 범위에 따라 접근 가능한 메뉴와 정보가 결정됩니다.

| 역할 | 범위 | 주요 대상 |
|---|---|---|
| **구성원(member)** | 본인의 세션·볼륨·지갑 | 일반 사용자 |
| **부서 관리자(group_admin)** | 단일 부서: 소속 구성원, 구성원의 세션, 부서 크레딧 풀 | 팀장 / 프로젝트 리더 |
| **조직 관리자(org_admin)** | 단일 조직: 소속된 전체 부서 및 사용자, 조직 예산 | 부서장 / 연구실 책임자 |
| **시스템 관리자(super_admin)** | 플랫폼 전체: 조직, 오퍼링, 정책, 클러스터, 노드, 스토리지, 이미지 | 플랫폼 운영자 / 시스템 관리자 |

모든 역할은 **명확한 권한 범위(Scope)**를 가집니다. 예를 들어 *비전팀*의 부서 관리자는 *NLP팀*의 자원이나 사용자 정보에 접근할 수 없으며, 특정 조직의 조직 관리자 역시 타 조직의 데이터에는 접근할 수 없습니다. 단, 동일한 사용자라도 소속된 부서에 따라 서로 다른 역할을 부여받을 수 있습니다.

## 역할별 권한

| 권한 | 구성원 | 부서 관리자 | 조직 관리자 | 시스템 관리자 |
|---|---|---|---|---|
| 본인 세션·볼륨·지갑 관리 | ✅ | ✅ | ✅ | ✅ |
| 세션 관제 및 감사 로그 조회 | — | 소속 부서 | 소속 조직 | 플랫폼 전체 |
| 사용자 및 부서 관리 | — | 소속 부서 | 소속 조직 | 플랫폼 전체 |
| 크레딧 배분 | 요청만 가능 | 부서 → 개인 | 조직 → 부서 | 충전 및 전체 관리 |
| 조직, 오퍼링, 전역 정책, 클러스터, 노드, 스토리지, 이미지 관리 | — | — | — | ✅ |

## 두 종류의 관리자 메뉴

[테넌트 관리](./dashboard.md) 메뉴는 조직 및 부서 관리자가 일상적으로 활용하는 기능입니다. [사용자](./users.md) 및 [크레딧](./credits.md) 관리, [실행 중인 세션 관제](./monitoring.md), [감사 로그](./audit.md) 조회를 수행합니다. 반면 [플랫폼 관리](./resources.md) 메뉴는 시스템 관리자 전용 공간으로 인프라 및 핵심 시스템 자원을 관리합니다. [GPU 카탈로그](./resources-offerings.md), [클러스터](./clusters.md) 및 [노드](./nodes.md), [스토리지](./storage.md), [이미지](./images.md), [시스템 설정](./system.md) 등을 제어할 수 있습니다.

## 주요 상황별 담당자 안내

| 상황 | 담당 및 해결 방법 |
|---|---|
| "크레딧 추가 발급이 필요합니다." | 해당 사용자의 소속 부서 관리자 — [크레딧 요청](./credits-requests.md) |
| "자원 할당 쿼터 상향이 필요합니다." | 해당 정책의 관리 권한자 (부서 정책: 부서 관리자, 전역 정책: 시스템 관리자) — [자원 증액 요청](./resources-policies.md#자원-증액-요청) |
| "특정 사용자가 GPU 자원을 점유한 채 사용하지 않습니다." | 해당 범위 내 관리 권한자 — [세션 개입](./monitoring-control.md) 또는 유휴 제한 시간(Idle Timeout) 조정 |
| "신규 구성원이 추가되었습니다." | 조직 관리자 — [사용자 추가](./users-add.md) (부서 관리자는 기존 사용자를 소속 부서로 추가 가능) |
| "인프라 노드 점검이 필요합니다." | 시스템 관리자 — [노드 비우기(Drain)](./nodes.md#비우기) |
| "스토리지 풀 용량이 부족합니다." | 시스템 관리자 — [스토리지 관리](./storage.md) |
| "세션이 *unserviceable* 오류로 실행되지 않습니다." | 시스템 관리자 — [오퍼링](./resources-offerings.md) 설정과 실제 GPU 카드 사양의 불일치 여부 확인 |

## 영구 작업 및 실행 취소 기능

영구적이며 복구 불가능한 작업(사용자, 부서, 조직, 클러스터, 오퍼링, 프리셋, 볼륨 삭제 등)을 수행할 때는 안전을 위해 대상의 명칭을 직접 입력해야 합니다. 반면 복구가 *가능한* 작업(예: 관리자 권한 해제)은 즉시 반영되며, 수행 후 수 초 동안 화면에 **실행 취소(Undo)** 옵션이 제공됩니다.
