# 지갑과 크레딧

모든 사용자는 **개인 지갑**을 가집니다. GPU 세션 시간은 이 지갑에서만 과금됩니다. 세션이 다른
사람의 지갑이나 부서에 청구되는 일은 없습니다.

![지갑](/img/screens/wallet.png)

## 과금 방식

- GPU 세션은 **시간당 단가 × 점유율 × 실행 시간**으로 과금됩니다. 단가는 GPU 모델의 것이고, 점유율은
  카드에서 차지한 비율(VRAM 또는 코어 중 큰 쪽)입니다. 카드의 ⅛이면 단가의 ⅛입니다.
- 세션이 시작되면 예상 실행 시간만큼 **예약(hold)**이 잡힙니다. 실행 중에 예약이 소비되고, 종료
  시 미사용분이 **환불**됩니다.
- **CPU 세션과 볼륨은 무료입니다.** GPU 세션이 없으면 잔액은 줄지 않습니다.

지갑 페이지는 잔액, 현재 예약, 그리고 배분·소비·환불 전체 이력을 세션별 링크와 함께 보여 줍니다.

## 크레딧 요청

![크레딧 요청](/img/screens/wallet-request.png)

잔액이 부족하면 **크레딧 요청**으로 부서에 배분을 요청합니다. 금액과 짧은 사유를 적으면 부서 또는
조직 관리자가 승인·반려하고, 승인되면 크레딧이 지갑에 들어오며 알림을 받습니다.

관리자가 **월 리필**을 설정해 두었다면 매달 초 요청 없이 그 금액까지 지갑이 채워집니다.
