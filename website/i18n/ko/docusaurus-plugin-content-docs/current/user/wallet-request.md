# 크레딧 요청

크레딧 잔액이 부족한 경우 부서 관리자에게 크레딧 충전을 요청할 수 있습니다. **크레딧 요청** 메뉴는 개인 지갑 페이지 및 메인 대시보드에서 이용할 수 있습니다.

![크레딧 요청](/img/screens/wallet-request.png)

## 크레딧 요청 신청

신청 대화 상자 상단에 **요청 대상**(소속 부서 관리자)이 표시되며, 다음 항목을 입력하여 신청합니다.

- **요청 크레딧:** 필요한 크레딧 수량을 입력합니다.
- **사유:** 관리자 심사 시 전달될 사유를 작성합니다. 단순히 "크레딧 필요"와 같이 작성하기보다 "ImageNet 파인튜닝 작업용 GPU 40시간 소요 예정"과 같이 구체적인 작업 내용을 작성하면 신속한 승인 검토에 도움이 됩니다.

필요한 크레딧 용량은 [세션 생성 마법사](./sessions-create.md)에서 구성하려는 자원 스펙의 시간당 예상 단가를 확인한 후, 예상 작업 시간에 비례하여 산정할 수 있습니다. 작업 오류나 재시도 가능성을 고려하여 여유분을 일부 반영하여 요청하는 것을 권장합니다.

## 요청 처리 상태 확인

![크레딧 요청 탭](/img/screens/wallet-requests.png)

**크레딧 요청** 탭에서 제출한 요청 내역 및 진행 상태를 조회할 수 있습니다.

| 상태 | 설명 |
|---|---|
| **대기** | 부서 관리자의 심사 및 승인을 기다리는 중입니다. |
| **승인** | 요청이 승인되어 크레딧 지급이 완료된 상태입니다 ([거래 내역](./wallet-ledger.md)에서 지급 내역 확인 가능). |
| **반려** | 요청이 거절된 상태입니다. 관리자가 작성한 반려 사유가 함께 표시됩니다. |

요청 처리 결과는 알림 패널(상단 종 아이콘)을 통해 실시간으로 안내되며 내역이 지속 보관됩니다 ([알림](./account-notifications.md) 참고).

## 자원 한도 초과 시 처리 (크레딧 vs 쿼터)

크레딧 외에도 세션 생성을 제한하는 다양한 자원 쿼터 한도가 존재합니다. 세션 생성 실패 원인이 크레딧 부족이 아닌 **자원 쿼터 초과**(동시 실행 수, VRAM, 스토리지 한도 등)인 경우, 크레딧을 추가로 충전하더라도 세션을 생성할 수 없습니다. 이는 계정별 [자원 정책](./account-limits.md)에 해당하는 사항이므로 **자원 증액 요청**을 통해 해결해야 합니다.

| 발생 증상 | 신청할 항목 |
|---|---|
| 세션 생성/실행 시 *크레딧 부족* 오류 발생 | 크레딧 요청 |
| *쿼터 초과*, *동시 실행 한도 초과*, 스토리지 용량 부족 오류 발생 | [자원 증액 요청](./account-limits.md#증액-요청) |
| 세션이 대기 상태로 계속 유지됨 | 클러스터 내 가용 자원 부족 현상 (상기 두 요청과 무관, [대기열](./sessions-queue.md) 참고) |
