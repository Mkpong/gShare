# 알림

내가 보지 않는 동안 내 작업에 무슨 일이 있었는지 플랫폼이 알려 줍니다.

![알림 종](/img/screens/notification-bell.png)

상단 바의 **종 아이콘**에 읽지 않은 개수가 붙습니다. 열면 최근 알림이 나오고, 항목을 누르면 관련
대상 — 세션, 요청, 볼륨 — 으로 이동합니다. **모두 읽음**과 **모두 삭제**는 패널 헤더에 있습니다.

## 어떤 알림이 오나

| 이벤트 | 예시 |
|---|---|
| 대기 세션 등록·시작 | *세션 'sweep-lr' 대기열 등록: 지금은 여유 용량이 없습니다* |
| 세션 일시정지·재개 | *세션 'resnet-finetune' 일시정지: GPU 반환, 과금 중지* |
| 내가 아닌 것에 의한 종료 | 유휴 시간 초과, 최대 실행 시간, 크래시 루프, 노드 오프라인, 관리자의 강제 종료 |
| 크레딧 요청 처리 | *크레딧 요청 승인됨 — 500.00C가 지갑에 배분되었습니다* |
| 자원 증액 처리 | *자원 증액 승인됨: GPU_MEM_MB 24576* |
| 볼륨 공유·해제 | |

관리자는 별도의 알림(노드 오프라인 등)을 받습니다. 사용자에게는 본인 것만 옵니다.

## 알림 내역

![알림 내역](/img/screens/account-notifications.png)

**마이페이지 → 알림 내역**은 종에서 지운 것까지 포함한 전체 목록을 보관합니다. 지운 항목은 표시가
붙습니다. 사흘 전 세션을 무엇이 끝냈는지 확인하기 좋은 곳이고, 세션 자체의
[이벤트 로그](./sessions-manage.md#이벤트-로그)와 내용이 일치합니다.

## 이메일은 보내지 않습니다

gShare는 이메일을 보내지 않습니다. 알림은 콘솔에 남고, 그 알림이 가리키는 작업도 콘솔에 있습니다.
외부 알림이 필요하면 관리자가 API로 조직별
[웹훅](../reference/api.md#리소스-그룹)을 등록할 수 있습니다.
