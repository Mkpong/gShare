# 알림

화면을 보고 있지 않을 때도 작업 진행 상황 및 주요 시스템 이벤트를 확인할 수 있도록 플랫폼이 알림을 제공합니다.

![알림 종](/img/screens/notification-bell.png)

상단 바의 **종 아이콘**에서 읽지 않은 알림 개수를 확인할 수 있습니다. 아이콘을 클릭하면 최근 알림 목록이 표시되며, 특정 항목을 선택하면 해당 리소스(세션, 요청, 볼륨 등) 페이지로 바로 이동합니다. 알림 패널 상단에서 **모두 읽음** 및 **모두 삭제** 기능을 이용할 수 있습니다.

## 알림 종류

| 이벤트 | 메시지 예시 |
|---|---|
| 대기 세션 등록·시작 | *세션 'sweep-lr' 대기열 등록: 현재 여유 용량이 없습니다* |
| 세션 일시정지·재개 | *세션 'resnet-finetune' 일시정지: GPU 반납, 과금 중단* |
| 외부/시스템 요인에 의한 종료 | 유휴 시간 초과, 최대 실행 시간 초과, 크래시 루프, 노드 오프라인, 관리자 강제 종료 |
| 크레딧 요청 처리 | *크레딧 요청 승인됨 — 500.00C가 지갑에 지급되었습니다* |
| 자원 증액 처리 | *자원 증액 승인됨: GPU_MEM_MB 24576* |
| 볼륨 공유·해제 | |

관리자는 시스템 관련 별도 알림(노드 오프라인 등)을 추가로 수신하며, 일반 사용자에게는 본인 소유의 리소스 알림만 제공됩니다.

## 알림 내역

![알림 내역](/img/screens/account-notifications.png)

**마이페이지 → 알림 내역**에서는 알림 패널에서 삭제된 항목을 포함한 전체 알림 기록을 보관합니다. 삭제된 항목에는 별도 표시가 적용됩니다. 지난 세션의 종료 원인을 추적할 때 유용하며, 세션별 [이벤트 로그](./sessions-manage.md#이벤트-로그) 내용과 동일하게 연동됩니다.

## 이메일 알림 정책

gShare는 별도의 이메일 알림을 발송하지 않습니다. 모든 알림과 해당 리소스 관리 작업은 웹 콘솔 내에서 제공됩니다.
외부 시스템으로 알림을 전달해야 하는 경우, 관리자가 API를 통해 조직별 [웹훅](../reference/api.md#주요-리소스-그룹)을 등록하여 연동할 수 있습니다.
