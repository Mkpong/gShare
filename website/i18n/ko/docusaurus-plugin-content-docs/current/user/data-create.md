# 볼륨 만들기

**데이터/볼륨 → 새 볼륨**이 대화 상자 하나를 엽니다.

![새 볼륨](/img/screens/data-new.png)

## 항목

### 볼륨 이름

소문자·숫자·하이픈이 읽기 좋습니다. 나중에 마운트 경로에 그대로 쓰게 되기 때문입니다.
`ImageNet (최종!)`보다 `imagenet-2024`가 낫습니다.

### 소유 범위

- **개인 (내 계정)** — 내 것입니다. [공유](./data-share.md)하기 전에는 아무도 보지 못합니다.
- **부서 공유** — 부서 관리자에게만 보입니다. 만드는 즉시 그 부서의 모든 구성원이 마운트할 수
  있습니다. 따로 공유할 필요가 없습니다.
- **전체** — 시스템 관리자에게만 보입니다. 로그인한 모든 사용자가 마운트할 수 있습니다. 누구나
  파일을 고쳐도 되는 경우가 아니면 읽기전용으로 두세요.

**대상**은 범위에 따라 자동으로 정해집니다. 내 계정, 고른 부서, 또는 전체.

### 종류

데이터셋, 개인 작업공간, 부서 공유, 임시 작업공간 —
[개요의 표](./data.md#종류)를 보세요. 고른 종류의 설명이 한 줄로 표시됩니다.

### 접근모드

| 모드 | 뜻 |
|---|---|
| **읽기/쓰기 (RWX)** | 세션이 쓸 수 있습니다. 여러 세션이 동시에 마운트할 수 있습니다. |
| **읽기전용 (ROX)** | 어떤 세션에서도, 소유자조차 쓸 수 없습니다. |

이것이 볼륨의 상한입니다. 읽기/쓰기 볼륨을 세션에서 읽기전용으로 마운트할 수는 있지만(마법사가
선택지를 줍니다) 그 반대는 안 됩니다. 실수로 지우면 안 되는 데이터셋은 읽기전용으로 만드는 편이
안전합니다.

### 쿼터 (GiB)

볼륨이 담을 수 있는 용량입니다. 두 가지 상한이 걸리고 대화 상자가 둘 다 보여 줍니다.

- **정책의 스토리지 한도** — 그림에서는 *70 / 500 GiB 사용 · 잔여 430 GiB*. 내 모든 볼륨의
  합계 기준입니다.
- **스토리지 서버에 실제로 남은 용량**.

둘 중 하나를 넘으면 제출 전에 거부되며, 지금 만들 수 있는 최대 값을 알려 줍니다.

## 만든 뒤에

볼륨은 사용량 0 GiB로 즉시 목록에 나타납니다. 실제 스토리지는 지연 생성됩니다. **처음 마운트하는
세션**이 실제 클레임을 만듭니다. 한 번도 마운트하지 않은 볼륨이 아무것도 차지하지 않는 것은
정상입니다.

어느 시점에도 과금은 없습니다. [볼륨은 무료](./data.md)이며 크레딧이 아니라 쿼터로 제한됩니다.

## 나중에 늘리기

쿼터는 나중에 언제든 올릴 수 있고([용량 변경](./data-manage.md#쿼터-변경)) 저장된 양보다 작게
줄일 수는 없습니다. 처음에 작게 시작해도 손해가 없습니다.
