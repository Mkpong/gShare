# 볼륨 만들기

**데이터/볼륨 → 새 볼륨** 메뉴를 선택하면 볼륨 생성 대화 상자가 표시됩니다.

![새 볼륨](/img/screens/data-new.png)

## 설정 항목

### 볼륨 이름

볼륨 이름은 추후 마운트 경로에 직접 사용되므로 영문 소문자, 숫자, 하이픈(`-`) 조합으로 작성하는 것을 권장합니다. (예: `ImageNet (최종!)` 대신 `imagenet-2024` 사용 권장)

### 소유 범위

- **개인 (내 계정):** 생성자 전용 볼륨입니다. [별도 공유](./data-share.md) 전까지 다른 사용자에게 노출되지 않습니다.
- **부서 공유:** 부서 관리자에게만 생성 권한이 표시되며, 생성 시 해당 부서 소속 모든 구성원이 별도 공유 절차 없이 바로 마운트할 수 있습니다.
- **전체:** 시스템 관리자에게만 생성 권한이 표시되며, 로그인한 모든 사용자가 마운트할 수 있습니다. 데이터 수정 및 삭제 방지를 위해 읽기 전용 설정을 권장합니다.

**소유 대상**은 선택한 범위(내 계정, 선택한 부서, 전체)에 따라 자동으로 지정됩니다.

### 종류

데이터셋, 개인 작업공간, 부서 공유, 임시 작업공간 등 용도에 따라 선택합니다. 상세 정보는 [데이터 개요](./data.md#볼륨-종류)를 참고하세요. 종류 선택 시 하단에 해당 용도에 대한 간단한 설명이 표시됩니다.

### 접근 모드

| 모드 | 설명 |
|---|---|
| **읽기/쓰기 (RWX)** | 세션에서 데이터 수정이 가능하며, 여러 세션에서 동시에 마운트할 수 있습니다. |
| **읽기 전용 (ROX)** | 소유자를 포함한 모든 세션에서 데이터를 수정할 수 없습니다. |

접근 모드는 볼륨의 최대 권한 범위를 결정합니다. 읽기/쓰기 볼륨을 세션 생성 시 읽기 전용 모드로 마운트할 수는 있지만(세션 생성 마법사에서 선택 가능), 읽기 전용 볼륨을 읽기/쓰기 모드로 마운트하는 것은 불가능합니다. 실수로 삭제되거나 변경되면 안 되는 중요 데이터셋은 읽기 전용으로 생성하는 것이 안전합니다.

### 쿼터 (GiB)

볼륨에 할당할 최대 용량을 설정합니다. 생성 시 다음 두 가지 제한 조건이 적용되어 대화 상자에 함께 표시됩니다.

- **사용자 정책의 스토리지 한도:** 보유한 모든 볼륨 용량의 합계 기준 (예: *70 / 500 GiB 사용 · 잔여 430 GiB*)
- **스토리지 서버의 실제 잔여 용량**

두 제한 중 하나라도 초과하는 용량을 입력하면 생성이 제한되며, 생성 가능한 최대 허용 용량이 안내됩니다.

## 생성 후 동작

생성된 볼륨은 사용량 0 GiB 상태로 목록에 즉시 추가되며, 실제 물리 스토리지는 **최초로 마운트되는 세션**이 실행될 때 생성됩니다. 따라서 마운트 이력이 없는 볼륨이 실제 용량을 차지하지 않는 것은 정상 동작입니다.

볼륨 사용 시 크레딧 과금은 발생하지 않습니다. [볼륨은 무료](./data.md)로 제공되며 자원 쿼터 정책의 제한만 받습니다.

## 쿼터 용량 변경

볼륨 쿼터 용량은 필요에 따라 언제든지 증액할 수 있습니다 ([용량 변경](./data-manage.md#쿼터-변경)). 단, 현재 저장된 데이터 용량보다 작게 축소할 수는 없습니다. 따라서 초기 생성 시에는 최소 필요한 용량으로 시작하는 것을 권장합니다.
