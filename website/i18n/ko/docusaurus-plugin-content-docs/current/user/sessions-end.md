# 세션 종료

종료는 되돌릴 수 없습니다. 정산하고, GPU를 반환하고, 컨테이너를 지웁니다. 다시 돌아올 생각이라면
[일시정지](./sessions-manage.md#일시정지)를 쓰세요.

## 세션 하나 종료

상세 페이지(또는 목록의 행)에서 **종료**를 누르면 먼저 확인합니다.

![종료 확인](/img/screens/session-terminate-confirm.png)

대화 상자는 세션 이름을 말하고, 무슨 일이 일어나는지 — 세션이 즉시 중지되고 GPU가 풀로 반환됩니다 —
그리고 무엇을 잃는지 알려 줍니다. **마운트한 볼륨 밖의 데이터는 컨테이너와 함께 사라집니다.**

## 돈은 어떻게 되나

1. 종료 시점에 과금이 멈춥니다.
2. 시작 때 잡힌 예약이 정산됩니다. 실제로 소비한 만큼 청구되고 **나머지는 지갑으로 환불**됩니다.
3. 최종 금액은 세션 행과 [지갑 이력](./wallet.md)에 세션과 함께 남습니다.

한 번도 시작되지 않은 세션 — [대기열](./sessions-queue.md)에서 취소한 세션 — 은 아예 과금되지
않습니다.

## 남는 것과 사라지는 것

| 남는 것 | 사라지는 것 |
|---|---|
| [마운트한 볼륨](./data.md)의 파일, 마운트한 경로 그대로 | 컨테이너 임시 디스크의 모든 것(설치한 패키지 포함) |
| 세션 기록, 이벤트 로그, 이력의 청구 내역 | 컨테이너와 그 프로세스, 연결 링크 |
| 볼륨 자체와 그 비용(없음) | GPU 예약 |

:::caution 볼륨을 먼저 확인하세요
JupyterLab 세션의 홈 디렉터리에 저장한 작업은 직접 옮기지 않았다면 볼륨이 아니라 임시 디스크에
있습니다. 종료하기 전에 남길 것을 마운트 경로로 복사하세요.
:::

## 여러 개 한 번에 종료

세션 목록에서 원하는 행을 체크하면 표 위에 툴바가 나타납니다.

![선택된 행](/img/screens/sessions-bulk.png)

![일괄 툴바](/img/screens/sessions-bulk-toolbar.png)

**선택 N개 종료**가 함께 끝내고, **선택 해제**가 목록을 되돌립니다.

![일괄 종료 확인](/img/screens/sessions-bulk-confirm.png)

확인 창은 끝낼 세션을 모두 이름으로 보여 줍니다. 다섯 개 이상이면 건수를 입력하도록 요구합니다.
여기서의 실수는 비싸고 되돌릴 수 없기 때문입니다.

## 끝난 뒤에

![종료된 세션](/img/screens/session-terminated.png)

종료된 세션도 페이지를 유지합니다. 점유했던 자원, 마운트했던 볼륨, 전체 이벤트 로그, 최종 비용을
그대로 읽을 수 있습니다. 실험을 되짚거나 청구 내역을 설명할 때 쓸모가 있습니다. 목록의 **종료** 탭이
같은 이력이고, **전체** 탭은 살아 있는 세션과 끝난 세션을 함께 보여 줍니다.

![전체 세션](/img/screens/sessions-all.png)
