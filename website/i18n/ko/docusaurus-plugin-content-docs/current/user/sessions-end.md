# 세션 종료

세션 종료 작업은 취소하거나 되돌릴 수 없습니다. 종료 시 크레딧 정산이 진행되며, 할당된 GPU 자원이 반납되고 세션 컨테이너가 삭제됩니다. 추후 작업을 재개할 가능성이 있다면 종료 대신 [일시정지](./sessions-manage.md#일시정지) 기능을 이용하세요.

## 단일 세션 종료

세션 상세 페이지 또는 세션 목록의 작업 메뉴에서 **종료** 버튼을 클릭하면 최종 확인 대화 상자가 표시됩니다.

![종료 확인](/img/screens/session-terminate-confirm.png)

대화 상자에는 대상 세션 이름과 함께 세션 즉시 중지, GPU 자원 반납 등의 주요 처리 내용과 데이터 삭제 주의사항이 안내됩니다. **마운트된 영구 볼륨 외부에 저장된 데이터는 컨테이너 삭제와 함께 모두 유실됩니다.**

## 비용 정산 안내

1. **과금 중단:** 세션 종료 시점부터 크레딧 차감이 즉시 중단됩니다.
2. **선예약 크레딧 정산:** 세션 시작 시 선예약된 금액 중 실제 사용한 시간만큼 정산되고, **남은 잔액은 개인 지갑으로 즉시 환불**됩니다.
3. **내역 기록:** 최종 정산된 크레딧 금액은 세션 상세 정보 및 [지갑 내역](./wallet.md)에 기록됩니다.

실제 실행되지 않고 [대기열](./sessions-queue.md) 상태에서 취소된 세션은 크레딧이 전혀 과금되지 않습니다.

## 데이터 보존 및 삭제 항목

| 보존되는 항목 | 삭제되는 항목 |
|---|---|
| [마운트된 볼륨](./data.md) 내 저장 데이터 (지정된 마운트 경로) | 컨테이너 임시 디스크 내 모든 데이터 (추가 설치 패키지 포함) |
| 세션 상세 정보, 이벤트 로그, 과금/정산 내역 | 세션 컨테이너, 실행 프로세스, 웹 접속 링크 |
| 마운트된 영구 볼륨 자체 및 관련 설정 (무료) | 할당된 GPU 자원 예약 |

:::caution 볼륨 저장 경로 확인 주의
JupyterLab 작업 시 기본 홈 디렉터리에 저장한 작업 파일은 영구 볼륨으로 직접 이동하지 않았다면 컨테이너 임시 디스크에 위치합니다. 세션을 종료하기 전에 중요한 작업 결과물은 마운트된 볼륨 경로로 반드시 복사하세요.
:::

## 여러 세션 일괄 종료

세션 목록에서 다중 선택 체크박스를 지정하면 상단에 일괄 작업 툴바가 활성화됩니다.

![선택된 행](/img/screens/sessions-bulk.png)

![일괄 툴바](/img/screens/sessions-bulk-toolbar.png)

**선택 N개 종료** 버튼을 통해 선택한 세션들을 동시에 종료할 수 있으며, **선택 해제**를 눌러 선택 상태를 취소할 수 있습니다.

![일괄 종료 확인](/img/screens/sessions-bulk-confirm.png)

최종 확인 창에 종료 대상 세션들의 이름 목록이 표시됩니다. 5개 이상의 세션을 일괄 종료하는 경우, 오작동 및 데이터 유실 사고를 방지하기 위해 전체 세션 수량을 직접 입력해야 최종 종료가 진행됩니다.

## 종료 후 세션 기록

![종료된 세션](/img/screens/session-terminated.png)

세션이 종료된 후에도 해당 세션의 상세 페이지는 유지됩니다. 할당되었던 자원 스펙, 마운트했던 볼륨 정보, 전체 이벤트 로그, 최종 정산 비용 등의 이력을 언제든지 조회할 수 있어 과거 실험 복기 및 과금 내역 검증 시 유용합니다. 세션 목록의 **종료** 탭에서 종료된 세션만 모아볼 수 있으며, **전체** 탭에서는 현재 실행 중인 세션과 종료된 세션을 한눈에 확인할 수 있습니다.

![전체 세션](/img/screens/sessions-all.png)
