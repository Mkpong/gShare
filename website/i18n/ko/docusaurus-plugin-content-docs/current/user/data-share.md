# 볼륨 공유

소유한 볼륨의 **공유** 버튼을 통해 다른 사용자에게 볼륨 접근 권한을 부여할 수 있습니다.

![공유 대화 상자](/img/screens/data-share.png)

## 권한 부여

권한을 부여할 대상의 **이메일 주소**를 입력하고 역할을 선택한 후 저장합니다.

| 역할 | 권한 범위 |
|---|---|
| **읽기 전용** | 사용자 세션에 읽기 전용 모드로만 마운트 가능 |
| **읽기/쓰기** | 읽기/쓰기 또는 읽기 전용 모드로 마운트 및 파일 수정 가능 |

공유받은 사용자는 볼륨 삭제, 쿼터 변경, 재공유 등의 관리 권한을 갖지 않으며, 해당 권한은 볼륨 소유자에게만 부여됩니다.

대화 상자 하단에는 현재 볼륨이 공유 중인 사용자 목록과 **해제** 버튼이 함께 표시됩니다. 공유 해제는 즉시 적용되며, 이미 실행 중인 세션에서는 세션 종료 시까지 마운트 상태가 유지되지만 신규 세션에서는 해당 볼륨을 마운트할 수 없습니다.

공유 설정된 볼륨은 목록에 **공유됨** 태그가 표시되어 외부 사용자와 공유 중인 자원임을 직관적으로 확인할 수 있습니다.

## 부서·전체 범주의 볼륨

**부서** 또는 **전체** 범위로 생성된 볼륨은 별도의 사용자 초대 절차 없이 조직 구조에 의해 자동으로 공유됩니다. 해당 부서 구성원(또는 전체 사용자)은 볼륨 생성 시 설정된 접근 모드에 따라 즉시 마운트하여 사용할 수 있으며, 개별 사용자 권한 추가 및 해제 설정은 제공되지 않습니다.

## 공유받은 볼륨

다른 사용자로부터 공유받은 볼륨은 목록에 **공유 · 소유자** 형태로 표시되며, 세션 생성 마법사에서 본인 소유의 볼륨과 동일하게 선택할 수 있습니다. 단, 다음과 같은 차이점이 있습니다.

- 쿼터 용량 변경, 잠금, 삭제 등의 관리 작업을 수행할 수 없습니다.
- 읽기 전용 권한으로 공유받은 경우 세션 마운트 모드가 읽기 전용으로 고정됩니다.
- 스토리지 용량은 **소유자의** 자원 쿼터에 차감되며, 공유받은 사용자의 쿼터에는 영향을 주지 않습니다.

![공유 해제](/img/screens/data-leave-confirm.png)

**공유 해제** 기능은 내 볼륨 목록에서 해당 항목을 제거하는 기능입니다. 실제 볼륨과 저장된 데이터는 소유자의 계정에 그대로 유지됩니다. 타인의 데이터를 삭제하는 것이 아닌 내 목록 보기에서만 제외하는 기능이므로, 향후 다시 사용해야 할 경우 소유자에게 재공유를 요청해야 합니다.

:::caution 데이터 접근 권한 주의
볼륨 공유는 데이터를 복사하는 것이 아니라 동일한 원본 데이터에 대한 접근 권한을 부여하는 기능입니다. 읽기/쓰기 모드로 공유된 볼륨은 권한을 가진 모든 사용자가 원본 데이터를 수정하거나 덮어쓸 수 있습니다. 데이터 훼손을 방지해야 하는 중요 데이터셋은 읽기 전용으로 공유하거나 최초 생성 시 읽기 전용 모드로 설정하세요.
:::
