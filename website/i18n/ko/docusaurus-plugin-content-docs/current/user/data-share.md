# 볼륨 공유

내가 소유한 볼륨의 **공유** 버튼이 다른 사람에게 접근 권한을 줍니다.

![공유 대화 상자](/img/screens/data-share.png)

## 권한 주기

상대의 **이메일 주소**를 입력하고 역할을 골라 저장합니다.

| 역할 | 할 수 있는 것 |
|---|---|
| **읽기전용** | 자기 세션에 읽기전용으로 마운트 |
| **읽기·쓰기** | 어느 모드로든 마운트하고 파일 수정 |

공유받은 사람은 볼륨을 삭제하거나, 쿼터를 바꾸거나, 다시 공유할 수 없습니다. 그것은 소유자의
몫입니다.

대화 상자에는 지금 공유 중인 사람이 **해제** 버튼과 함께 나열됩니다. 해제는 즉시 적용됩니다. 이미
실행 중인 세션은 끝날 때까지 마운트를 유지하지만, 새 세션은 마운트할 수 없습니다.

공유한 볼륨에는 목록에서 **공유됨** 태그가 붙으므로, 내 볼륨 중 어느 것에 다른 사람이 의존하고
있는지 한눈에 보입니다.

## 부서·전체 볼륨

**부서** 또는 **전체** 범위로 만든 볼륨은 구조상 이미 공유 상태입니다. 부서의 모든 구성원(또는 모든
사용자)이 초대 없이 볼륨 자체의 접근 모드로 마운트할 수 있습니다. 줄 권한도, 해제할 권한도
없습니다.

## 공유받은 볼륨

내 목록에 **공유 · 소유자** 범위로 나타나고, 마법사에서 내 볼륨처럼 고를 수 있습니다. 다른 점은:

- 쿼터 변경·잠금·삭제를 할 수 없습니다.
- 읽기전용으로 공유받았다면 세션 마운트도 읽기전용으로 고정됩니다.
- **소유자의** 스토리지 쿼터에 잡힙니다. 내 쿼터가 아닙니다.

![공유 해제](/img/screens/data-leave-confirm.png)

**공유 해제**는 내 목록에서만 제거합니다. 볼륨과 데이터는 소유자에게 그대로 남습니다. 남의 데이터를
지우는 기능이 아니라 내 목록을 정리하는 기능입니다. 다시 필요하면 소유자에게 공유를 부탁하세요.

:::caution 공유는 복사가 아니라 접근입니다
읽기/쓰기로 공유한 볼륨은 공유받은 모두가 파일을 덮어쓸 수 있습니다. 바뀌면 안 되는 데이터셋은
읽기전용으로 공유하거나, 애초에 읽기전용으로 만드세요.
:::
