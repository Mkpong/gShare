# 세션 관리

실행 중이거나 활성화된 세션에 대한 모든 관리 작업은 세션 상세 페이지에서 수행할 수 있습니다.

![실행 중 세션의 동작](/img/screens/session-actions.png)

| 버튼 | 설명 |
|---|---|
| **일시정지** | 컨테이너 실행을 중지하고 **GPU 자원을 반납**하며 **크레딧 차감을 중단**합니다. 세션 설정, 연결된 볼륨, 크레딧 선예약 상태는 유지됩니다. |
| **재시작** | 세션을 일시정지한 후 즉시 다시 실행합니다. 내부 프로세스가 응답하지 않을 때 빠르게 복구할 수 있습니다. |
| **종료** | 세션을 완전히 종료하고 크레딧을 정산합니다. 자세한 내용은 [세션 종료](./sessions-end.md)를 참고하세요. |
| **연결** | 웹 접속 링크 패널을 엽니다 ([접속하기](./sessions-connect.md) 참고). |

## 일시정지

**일시정지**는 작업을 잠시 중단할 때 자원을 효율적으로 관리하는 방법입니다. 할당된 GPU 자원을 반납하여 다른 사용자가 이용할 수 있도록 하고, 불필요한 크레딧 소모를 방지합니다.

![일시정지된 세션](/img/screens/session-paused.png)

세션 상태에 **일시정지** 표시와 함께 중지 사유(*사용자 직접 중지* 또는 유휴 정책에 의한 *유휴 중지*)가 안내됩니다. 컨테이너 종료에 따라 임시 디스크 데이터는 삭제되지만, 마운트된 영구 볼륨과 내부 데이터는 안전하게 보존되며 별도의 유지 비용도 발생하지 않습니다.

![일시정지된 세션의 동작](/img/screens/session-paused-actions.png)

**재개** 버튼을 누르면 GPU 자원을 다시 할당받습니다. 사용 가능한 여유 자원이 있으면 수 초 내에 세션이 재개되며, 자원이 부족한 경우 [대기열](./sessions-queue.md)에 진입하여 순차적으로 자동 실행됩니다. 기존 세션 이름, 이미지, 볼륨 마운트 설정은 그대로 유지됩니다.

:::note 유휴 세션 자동 일시정지 안내
시스템 정책으로 설정된 유휴 시간(기본 설정: 1시간) 동안 GPU 자원 사용이 없는 세션은 불필요한 크레딧 소모를 방지하기 위해 자동으로 일시정지됩니다. 저장된 영구 데이터는 유실되지 않으며, 언제든지 재개하여 작업을 이어할 수 있습니다.
:::

## 실행 중 모니터링

![실시간 사용량](/img/screens/session-live.png)

**실시간 사용량** 패널에서는 최근 15분·1시간·6시간 동안의 CPU, 메모리, GPU 코어, VRAM 사용률 그래프를 제공합니다. 노드 에이전트가 설치된 환경에서는 CPU 및 메모리를 1초 간격으로 실시간 수집하여 표시하며, GPU 모니터링 수치는 수집 주기에 따라 수 초의 지연이 발생할 수 있습니다. VRAM 사용량은 실제 CUDA 컨텍스트가 활성화되어 작업이 진행 중일 때만 연동되어 표시됩니다.

![자원](/img/screens/session-resources.png)

**자원** 카드에서는 세션에 할당된 점유 자원 스펙을 보여줍니다. 자원 클래스, 공유 방식(전용/분할), VRAM, GPU 코어, CPU, 메모리, 임시 디스크 사용량 및 현재까지의 **누적 크레딧 소모량**을 확인할 수 있습니다.

![메타](/img/screens/session-meta.png)

**메타** 패널에는 세션의 식별 정보와 실행 환경이 표시됩니다. 세션 고유 ID(복사 버튼 제공), 생성 및 시작 시각, 마운트된 볼륨 목록(마운트 모드 및 경로), 할당된 실제 GPU 카드 정보, 사용 중인 컨테이너 이미지 정보를 조회할 수 있습니다.

## 이벤트 로그

![이벤트 로그](/img/screens/session-events.png)

세션 상태 변화 및 시스템 이벤트 기록이 상태 변경 사유와 함께 시계열로 기록됩니다 (대기 시간, 세션 시작, 일시정지, 재개, 종료 등). 이미지 풀링 실패, 컨테이너 비정상 종료, 노드 오프라인 장애 발생 시 원인 분석을 위해 이 로그를 확인할 수 있습니다.

## 재시작 활용 안내

**재시작** 기능은 세션 일시정지 후 재개 과정을 연속으로 실행합니다. 세션 내부 프로세스가 중단되거나 오류가 발생했을 때 현재 세션 환경과 볼륨 마운트 상태를 유지하면서 컨테이너를 재부팅하는 데 유용합니다. 단, 재시작을 통해 GPU 할당 자원 용량을 변경할 수는 없습니다. 자원 스펙을 변경해야 하는 경우 현재 세션을 종료한 후 원하는 자원 옵션으로 새 세션을 생성해야 합니다.
