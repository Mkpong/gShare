# 세션 관리

살아 있는 세션에 하는 일은 모두 상세 페이지에 있습니다.

![실행 중 세션의 동작](/img/screens/session-actions.png)

| 버튼 | 하는 일 |
|---|---|
| **일시정지** | 컨테이너를 내리고 **GPU를 반환**하며 **과금을 멈춥니다**. 세션·볼륨·크레딧 예약은 유지됩니다. |
| **재시작** | 일시정지 후 곧바로 재개. 프로세스가 먹통일 때 가장 빠른 길입니다. |
| **종료** | 세션을 완전히 끝내고 정산합니다. [세션 종료](./sessions-end.md)를 보세요. |
| **연결** | [접속하기](./sessions-connect.md)의 링크를 엽니다. |

## 일시정지

일시정지는 잠시 자리를 비우는 예의 바른 방법입니다. 카드를 돌려주어 다른 사람이 쓸 수 있게 하고,
잔액이 줄지 않게 합니다.

![일시정지된 세션](/img/screens/session-paused.png)

상태 줄에 **일시정지**와 그 이유가 뜹니다 — *본인이 중지함*, 또는 정책이 대신 멈춘 경우 *유휴*.
임시 디스크는 컨테이너와 함께 사라지고, 볼륨과 그 안의 모든 것은 그대로이며 유지 비용도 없습니다.

![일시정지된 세션의 동작](/img/screens/session-paused-actions.png)

**재개**는 GPU를 다시 요청합니다. 빈 자리가 있으면 몇 초 만에 돌아오고, 꽉 차 있으면
[대기열](./sessions-queue.md)에서 기다리다 스스로 올라옵니다. 이름, 이미지, 마운트는 그대로입니다.

:::note 유휴 세션은 대신 일시정지됩니다
사이트 정책이 유휴 시간을 정합니다(기본 카탈로그는 1시간). 그 시간 동안 카드가 아무 일도 하지 않은
GPU 세션은 자동으로 일시정지되어, 잊고 둔 노트북이 밤새 카드를 쥐고 있지 않게 합니다. 잃는 것은
없습니다. 재개하고 이어서 하세요.
:::

## 실행 중 지켜보기

![실시간 사용량](/img/screens/session-live.png)

**실시간 사용량** 패널은 최근 15분·1시간·6시간의 CPU, 메모리, GPU 코어, VRAM을 그립니다. 노드
에이전트가 배포된 곳에서는 CPU와 메모리를 1초마다 측정해 *실시간 1초*로 표시하고, GPU 값은 기존 수집
경로를 거쳐 몇 초 지연됩니다. VRAM은 CUDA 컨텍스트가 열려 있을 때만 0보다 크게 나옵니다. 놀고 있는
노트북은 0입니다.

![자원](/img/screens/session-resources.png)

**자원** 카드는 세션이 점유한 것입니다. 클래스, 공유 방식, VRAM, 코어, CPU, RAM, 디스크, 임시 디스크
사용량, 그리고 지금까지의 **예상 소모**.

![메타](/img/screens/session-meta.png)

**메타**는 출처와 위치입니다. 세션 ID(티켓용 복사 버튼 포함), 생성·시작 시각, 마운트한 볼륨과 그
모드·경로, 바인딩된 정확한 카드, 이미지 참조.

## 이벤트 로그

![이벤트 로그](/img/screens/session-events.png)

모든 전환이 사유와 함께 순서대로 남습니다. 대기(얼마나 기다렸는지 포함), 시작, 일시정지, 재개, 종료.
이미지를 받지 못했거나, 컨테이너가 죽었거나, 노드가 내려갔을 때 그렇게 적히는 곳입니다.

## 재시작은 언제 쓰나

**재시작**은 일시정지와 재개를 한 번에 합니다. 안의 프로세스가 멈췄지만 세션 자체는 그대로 쓰고 싶을
때 알맞습니다. 더 큰 GPU 조각을 얻는 방법은 **아닙니다**. 자원은 세션을 만들 때 정해졌습니다. 다른
자원이 필요하면 세션을 끝내고 새로 만드세요.
