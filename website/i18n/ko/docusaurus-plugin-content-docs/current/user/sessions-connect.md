# 세션에 접속하기

실행 중인 세션은 브라우저에서 바로 열립니다. SSH도, 설치할 클라이언트도 없습니다. 세션 상세
페이지의 **연결**이 컨테이너로 들어가는 링크를 발급합니다.

![연결](/img/screens/session-connect.png)

## 들어가는 세 가지 길

| 링크 | 열리는 것 |
|---|---|
| **code** | code-server — 브라우저의 VS Code. 세션의 파일시스템과 터미널을 그대로 씁니다 |
| **lab** | JupyterLab — 노트북, 파일 브라우저, 터미널 |
| **terminal** | ttyd — 가장 가벼운 셸 하나 |

셋 다 **세션 컨테이너 안에서** 돕니다. 같은 파일, 같은 GPU, 같은 마운트 볼륨을 봅니다. 동시에 둘을
열어도 됩니다.

## 일회용 링크

각 링크에는 만료가 짧은 일회용 토큰이 붙고, 옆에 남은 시간이 표시됩니다. 첫 요청이 토큰을 짧은
쿠키로 바꾸고 링크는 그 순간 소모됩니다. 한참 두었던 링크나 남에게 전달한 링크가 동작하지 않는
이유가 이것입니다.

**재발급**이 새 링크 묶음을 만듭니다. 만료된 링크를 새로고침하지 말고 재발급하세요.

패널에는 원본 URL과 토큰도 복사 버튼과 함께 있습니다. 티켓에 붙이거나 세션에 접근해야 하는
스크립트에 넣을 때 쓰세요.

:::caution 링크가 곧 접근 권한입니다
아직 쓰이지 않은 링크를 가진 사람은 내 세션과 데이터에 들어올 수 있습니다. 비밀번호처럼 다루고,
공용 채널에 붙여 넣지 마세요.
:::

## 안에서 할 수 있는 것

- 세션이 점유한 GPU 조각으로 노트북과 스크립트를 실행합니다.
- 지정한 경로에서 [마운트한 볼륨](./data.md)을 읽고 씁니다.
- 컨테이너에 패키지를 설치합니다(`pip install …`). 임시 디스크에 저장되므로 세션이 끝나면
  사라집니다. 남아야 할 것은 볼륨이나 [이미지](../admin/images.md)에 두세요.
- `apt install`은 세션을 **권한 있는 세션**으로 만들었을 때만 됩니다.

## 연결이 제공되지 않을 때

**실행중**이 아니면 버튼이 비활성화됩니다.

- **대기** — 아직 자원을 기다리거나 시작하는 중입니다. 기다리거나
  [대기열](./sessions-queue.md)을 확인하세요.
- **일시정지** — 컨테이너가 없습니다. 먼저 **재개**하세요.
  [세션 관리](./sessions-manage.md)를 보세요.
- **종료됨** — 끝난 세션입니다. 새로 만드세요.

실행 중인데도 링크가 오류를 내면 재발급하세요. 그래도 안 되면 세션의
[이벤트 로그](./sessions-manage.md#이벤트-로그)가 컨테이너에 무슨 일이 있었는지 알려 줍니다.
