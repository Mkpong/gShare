# 세션에 접속하기

실행 중인 세션은 별도의 SSH 설정이나 클라이언트 설치 없이 브라우저에서 바로 접속할 수 있습니다. 세션 상세 페이지의 **연결** 패널에서 컨테이너 접속 링크를 발급받아 접근할 수 있습니다.

![연결](/img/screens/session-connect.png)

## 세 가지 접속 방법

| 링크 | 접속 환경 |
|---|---|
| **code** | code-server (웹 기반 VS Code) — 세션의 파일 시스템과 터미널 환경을 동일하게 사용합니다. |
| **lab** | JupyterLab — Jupyter 노트북, 파일 브라우저, 터미널 환경을 제공합니다. |
| **terminal** | ttyd — 경량화된 웹 터미널 셸 환경을 제공합니다. |

세 가지 접속 환경 모두 **세션 컨테이너 내부**에서 동작합니다. 동일한 파일, GPU 자원, 마운트된 볼륨을 공유하므로 필요 시 여러 접속 환경을 동시에 열어 작업할 수 있습니다.

## 일회용 접속 링크

발급되는 각 링크에는 유효 시간이 짧은 일회용 토큰이 포함되어 있으며, 링크 옆에 남은 유효 시간이 표시됩니다. 접속 요청 시 토큰이 인증 쿠키로 변환되며 해당 링크는 즉시 만료됩니다. 일정 시간이 지나거나 타인에게 전달한 링크가 작동하지 않는 것은 이 때문입니다.

**재발급** 버튼을 클릭하면 새로운 접속 링크 묶음이 생성됩니다. 만료된 링크 페이지를 새로고침하는 대신 재발급 버튼을 사용하세요.

연결 패널에서는 원본 URL 및 토큰 정보도 복사 버튼과 함께 제공됩니다. 지원 티켓에 첨부하거나 세션 접속용 스크립트에 포함할 때 활용할 수 있습니다.

:::caution 접속 링크 보안 주의
사용되지 않은 접속 링크를 보유한 사용자는 해당 세션 및 내 데이터에 접근할 수 있습니다. 접속 링크를 비밀번호와 같이 엄격하게 관리하고, 메신저 등 공용 채널에 노출되지 않도록 주의하세요.
:::

## 세션 내부 주요 작업

- 할당된 GPU 자원을 활용하여 Jupyter 노트북 및 파이썬 스크립트를 실행할 수 있습니다.
- 지정된 마운트 경로를 통해 [연결된 볼륨](./data.md)의 데이터를 읽고 쓸 수 있습니다.
- 컨테이너 내부에 파이썬 패키지를 설치할 수 있습니다 (`pip install …`). 단, 패키지는 임시 디스크에 저장되므로 세션 종료 시 삭제됩니다. 영구 보존이 필요한 데이터는 볼륨에 저장하거나 맞춤형 [커스텀 이미지](../admin/images.md)를 구성하세요.
- 시스템 패키지 설치 (`apt install`)는 세션을 **권한 부여 세션(Privileged Session)**으로 생성한 경우에만 지원됩니다.

## 접속 버튼 비활성화 원인 및 조치

세션 상태가 **실행 중**이 아닌 경우 접속 버튼이 비활성화됩니다.

- **대기:** 자원 할당을 기다리거나 컨테이너를 생성 중인 상태입니다. 생성이 완료될 때까지 대기하거나 [대기열](./sessions-queue.md)을 확인하세요.
- **일시정지:** 컨테이너 실행이 중지된 상태입니다. 세션을 먼저 **재개**해야 접속할 수 있습니다 ([세션 관리](./sessions-manage.md) 참고).
- **종료됨:** 이미 종료된 세션입니다. 필요한 경우 새 세션을 생성하세요.

세션 상태가 실행 중임에도 접속 오류가 발생하는 경우 링크를 **재발급**해 보세요. 문제가 지속되면 세션의 [이벤트 로그](./sessions-manage.md#이벤트-로그)에서 오류 원인을 확인할 수 있습니다.
