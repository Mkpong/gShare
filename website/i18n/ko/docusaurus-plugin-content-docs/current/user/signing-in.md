# 로그인

관리자에게 받은 콘솔 주소를 열고 **이메일과 비밀번호**로 로그인합니다. 계정은 보통 관리자가 만들어
줍니다.

사이트가 허용한다면 로그인 화면에 **회원가입** 탭이 있습니다. 이름, 이메일(허용된 도메인), 8자 이상의
비밀번호. 사이트 정책에 따라 바로 쓸 수 있거나, 관리자가 승인하고 부서를 지정할 때까지 *대기* 상태로
있습니다. 그전까지는 아무것도 실행할 수 없습니다.

![로그인 화면](/img/screens/login.png)

## 첫 로그인

처음 로그인하면 관리자가 정해 준 **비밀번호를 바꾸도록** 요구합니다. 바꾸기 전에는 다른 화면으로
갈 수 없습니다. 본인만 아는 비밀번호를 고르세요. 관리자는 비밀번호를 초기화할 수는 있지만 볼 수는
없습니다.

## 언어와 테마

상단 바의 두 토글은 이 브라우저에만 적용됩니다.

- **EN / KO** — 콘솔 언어를 바꿉니다. 모든 화면·메시지·오류가 두 언어로 제공됩니다.
- **달 / 해** — 라이트·다크 테마를 바꿉니다.

## 클러스터 선택

사이드바 토글 옆의 알약 모양 버튼은 콘솔이 지금 보고 있는 **클러스터**를 나타냅니다(기본값
*전체 클러스터*). 모든 목록과 대시보드, 세션 마법사의 기본값이 이 선택으로 좁혀집니다. 대부분의
설치는 클러스터가 하나이므로 그대로 두면 됩니다. "왜 노드가 두 개만 보이지?"라는 질문의 답이 항상
상단 바에 보이도록 둔 것입니다.

## 로그아웃

사이드바 하단의 이름 메뉴에서 **로그아웃**을 선택합니다. 토큰이 만료되거나 관리자가 계정을
비활성화해도 로그아웃됩니다. 다시 로그인하면 됩니다.
