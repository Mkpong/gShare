# 로그인

관리자로부터 안내받은 콘솔 URL로 접속한 후 **이메일과 비밀번호**를 입력하여 로그인합니다. 일반적인 사용자 계정은 관리자가 사전 생성하여 제공합니다.

시스템 정책상 신규 회원가입을 허용하는 경우 로그인 화면에 **회원가입** 탭이 표시됩니다. 사용자 이름, 이메일(허용된 도메인) 및 8자 이상의 비밀번호를 입력하여 가입을 신청할 수 있습니다. 가입 정책에 따라 즉시 이용이 가능하거나, 관리자의 가입 승인 및 부서 배정이 완료될 때까지 *대기* 상태로 유지됩니다. 승인 대기 중에는 서비스 이용이 제한됩니다.

![로그인 화면](/img/screens/login.png)

## 최초 로그인

최초 로그인 시 관리자가 지정한 임시 **비밀번호를 변경해야** 합니다. 비밀번호 변경을 완료하기 전까지는 타 메뉴로 이동할 수 없습니다. 보안을 위해 본인만 알 수 있는 비밀번호를 설정하세요. (관리자는 비밀번호 초기화는 가능하지만, 설정된 비밀번호를 직접 조회할 수는 없습니다.)

## 언어 및 테마 설정

상단 바에 위치한 두 개의 토글 버튼을 통해 콘솔 표시 환경을 설정할 수 있으며, 설정값은 사용 중인 브라우저 로컬 환경에만 적용됩니다.

- **EN / KO:** 콘솔 표시 언어를 한국어 또는 영어로 전환합니다. 모든 메뉴, 설명 및 오류 메시지가 다국어로 제공됩니다.
- **달 / 해 아이콘:** 다크 모드 및 라이트 모드 테마를 전환합니다.

## 클러스터 선택

사이드바 토글 옆의 필터 버튼은 현재 콘솔에서 조회 중인 **클러스터** 환경을 나타냅니다 (기본값: *전체 클러스터*). 클러스터를 선택하면 대시보드, 각종 자원 목록 및 세션 생성 마법사의 기본 조회 범위를 지정된 클러스터로 제한합니다. 단일 클러스터 환경에서는 기본 설정(전체 클러스터)을 유지하면 됩니다.

## 로그아웃

사이드바 하단의 사용자 프로필 메뉴에서 **로그아웃**을 선택하여 접속을 종료합니다. 세션 토큰이 만료되거나 관리자에 의해 계정이 비활성화된 경우에도 자동 로그아웃 처리됩니다.
