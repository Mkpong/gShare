# 비밀번호

![비밀번호 변경](/img/screens/account-password.png)

**비밀번호 변경** 화면에서는 현재 비밀번호와 변경할 새 비밀번호(2회)를 입력합니다. 입력하는 동안 실시간으로 비밀번호 규칙(최소 8자 이상, 새 비밀번호 재입력 일치 여부)을 검증하며, 모든 조건이 충족되기 전까지 변경 버튼은 비활성화 상태(비활성화 사유 표시)를 유지합니다.

비밀번호를 변경해도 현재 실행 중인 세션에는 영향을 주지 않습니다.

## 첫 로그인

최초 계정은 관리자가 발급한 초기 비밀번호로 생성되며, 로그인 시 콘솔에서 가장 먼저 **비밀번호 변경을 요청**합니다. 비밀번호를 변경하기 전까지는 다른 페이지로 이동하더라도 다시 비밀번호 변경 화면으로 리다이렉트됩니다.

비밀번호는 본인만 알 수 있는 안전한 비밀번호로 설정하세요. 관리자는 비밀번호를 초기화할 수만 있으며, 사용자의 기존 비밀번호를 조회할 수 없습니다.

## 비밀번호를 잊은 경우

사용자가 직접 비밀번호를 재설정하는 기능은 제공되지 않습니다. 관리자(부서 또는 조직 관리자)에게 비밀번호 초기화를 요청해야 합니다. 관리자가 임시 비밀번호를 발급하면, 신규 계정과 마찬가지로 다음 로그인 시 새 비밀번호를 설정할 수 있습니다.

## 계정 보안 수칙

- **세션 접속 링크 보안:** VS Code나 JupyterLab 웹 IDE 접속 링크에는 인증 정보가 포함되어 있어, 링크 사용 및 만료 전까지 해당 세션과 데이터에 접근할 수 있습니다. 타인에게 공유하지 마세요 ([접속하기](./sessions-connect.md#일회용-접속-링크)).
- **공용 PC 사용 시 로그아웃:** 공용 환경에서는 사용 후 사용자 프로필 메뉴에서 반드시 **로그아웃**하세요.
- **로그인 기록 관리:** 로그인 시도(성공/실패)는 모두 [감사 로그](../admin/audit.md)에 기록되어 이상 접근 발생 시 관리자가 확인할 수 있습니다.
