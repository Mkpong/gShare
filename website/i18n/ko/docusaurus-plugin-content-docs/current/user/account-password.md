# 비밀번호

![비밀번호 변경](/img/screens/account-password.png)

**비밀번호 변경**은 현재 비밀번호와 새 비밀번호(두 번)를 묻습니다. 규칙은 입력하는 동안
검사합니다. 최소 8자, 그리고 새 비밀번호 두 칸이 일치해야 합니다. 그전까지 버튼은 이유와 함께
비활성 상태입니다.

비밀번호를 바꿔도 실행 중인 세션에는 영향이 없습니다.

## 첫 로그인

계정은 관리자가 정한 비밀번호로 시작하고, 콘솔은 다른 무엇보다 먼저 **비밀번호 변경을 요구**합니다.
바꾸기 전에는 모든 화면이 변경 폼으로 되돌아옵니다.

본인만 아는 것으로 고르세요. 관리자는 비밀번호를 초기화할 수는 있어도 볼 수는 없습니다.

## 잊었다면

셀프 재설정은 없습니다. 관리자(부서 또는 조직 관리자)에게 초기화를 요청하세요. 임시 비밀번호를
설정해 주면 새 계정과 똑같이 다음 로그인에서 새 비밀번호를 정하게 됩니다.

## 계정을 지키려면

- **세션 연결 링크도 자격 증명입니다.** VS Code나 JupyterLab으로 들어가는 링크는 사용되거나
  만료되기 전까지 내 세션과 데이터에 접근할 수 있습니다. 전달하지 마세요
  ([접속하기](./sessions-connect.md#일회용-링크)).
- 공용 PC에서는 이름 메뉴에서 **로그아웃**하세요.
- 로그인은 성공이든 실패든 [감사 로그](../admin/audit.md)에 남으므로, 누군가 시도했다면 관리자가
  볼 수 있습니다.
