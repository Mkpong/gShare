# 거래 내역

**거래 내역** 탭은 개인 지갑의 모든 크레딧 변동 이력을 관리하는 원장(Ledger)입니다. 크레딧의 모든 증감 및 차감 이력이 최신순으로 기록되며, 각 항목별 반영 후 잔액이 함께 표시됩니다.

![거래 내역](/img/screens/wallet-ledger.png)

![거래 내역 표](/img/screens/wallet-ledger-table.png)

| 열 | 설명 |
|---|---|
| **일시** | 변동 발생 시각입니다. 마우스 호버 시 정확한 타임스탬프가 표시되며, 사용 항목의 경우 과금 대상 기간이 함께 표시됩니다. |
| **유형** | 크레딧 변동 유형을 나타냅니다 (하단 상세 설명 참고). |
| **금액** | 차감/청구는 음수(`-`), 지급/환불은 양수(`+`)로 표시되며, 예약 항목은 선예약된 금액을 나타냅니다. |
| **이후 잔액** | 해당 변동 건이 반영된 직후의 가용 잔액입니다. |
| **참조** | 연관된 세션, 요청 건 또는 사유가 표시되며, 세션 이름을 클릭하면 해당 세션 상세 페이지로 이동합니다. |

## 변동 유형 상세

| 유형 | 설명 |
|---|---|
| **예약** | 세션 시작 시 선예약된 금액입니다 (실제 차감이 아닌 예치 개념). |
| **사용** | 세션 실행 시간에 따라 실제 차감된 크레딧입니다. |
| **정산** | 세션 종료 시 최종 확정된 과금 내역입니다. |
| **환불** | 선예약 금액 중 미사용 잔액에 대한 환불 내역입니다. |
| **조정** | 관리자에 의한 크레딧 변동 내역입니다 (크레딧 할당(`allocate-in`), 쿼터 요청 승인(`alloc-req`), 월간 정기 충전, 크레딧 회수 등). |
| **충전** | 시스템 레벨에서 발행된 크레딧 내역입니다. |

**참조** 열을 통해 크레딧 변동의 출처(세션 ID, *웰컴 크레딧*, *충전 승인* 등)를 확인할 수 있습니다.

사용 항목에는 다음 상태 태그가 부여됩니다.

- **과금 중:** 세션이 현재 실행 중인 상태로, 표시된 금액은 최종 확정 수치가 아닙니다.
- **정산됨:** 세션이 종료되어 최종 금액 정산이 완료된 상태입니다.

장시간 실행되는 세션의 경우 초 단위 기록 대신 일정 과금 주기 단위로 요약되어 기록됩니다. 과금 구간별로 1개 항목으로 집계되며, 마우스 호버 시 해당 구간에 포함된 세부 내역 수가 안내됩니다.

## 조회 및 필터링

- **검색:** 참조 열의 키워드(예: 세션 이름, 식별자)를 기반으로 내역을 검색합니다.
- **유형 필터:** 할당, 사용, 환불, 조정 등 변동 유형별로 필터링하여 조회합니다.
- **정렬 및 URL 공유:** 모든 열의 정렬을 지원하며, 필터 및 정렬 상태가 URL에 자동으로 반영되어 해당 링크를 그대로 공유할 수 있습니다.

## 세션 비용 교차 검증

**참조** 열의 세션 링크를 클릭하거나 세션 상세 페이지에서 표시되는 누적 크레딧 사용량을 세션 종료 후 원장의 정산 항목과 교차 검증할 수 있습니다. 세션 상세 페이지의 사용량 역시 지갑 원장 데이터를 기반으로 계산되므로 두 값은 정확히 일치합니다.

크레딧 수치에 이상이 있는 경우, 세션 ID(세션 상세 페이지에서 복사 가능) 및 해당 일시를 확인하여 관리자에게 문의하세요. 원장 및 [감사 로그](../admin/audit.md)에 모든 자원 및 크레딧 변동 이력이 기록 및 보관됩니다.
