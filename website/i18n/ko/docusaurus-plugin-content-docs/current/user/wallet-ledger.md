# 거래 내역

**거래 내역** 탭이 지갑의 원장입니다. 모든 이동이 최신순으로, 각 이동 뒤의 잔액과 함께 남습니다.

![거래 내역](/img/screens/wallet-ledger.png)

![거래 내역 표](/img/screens/wallet-ledger-table.png)

| 열 | 의미 |
|---|---|
| **일시** | 시각. 호버하면 정확한 값이 보입니다. 사용 행은 대상 구간을 함께 표시합니다 |
| **유형** | 어떤 행인지 — 아래 참고 |
| **금액** | 청구는 음수, 받거나 환불된 크레딧은 양수. 예약 행은 확보된 금액을 표시 |
| **이후 잔액** | 이 행이 반영된 뒤의 잔액 |
| **참조** | 관련된 세션·요청·사유. 세션 이름은 세션으로 이어집니다 |

## 행 유형

| 유형 | 내용 |
|---|---|
| **예약** | 세션이 시작될 때 잡힌 금액. 청구가 아니라 확보입니다 |
| **사용** | 세션 실행 구간에 대한 실제 청구 |
| **정산** | 세션이 끝날 때의 최종 확정 |
| **환불** | 예약의 미사용분 반환 |
| **조정** | 관리자가 옮긴 크레딧: 나에게 온 배분(`allocate-in`), 승인된 요청(`alloc-req`), 월 리필, 또는 풀로 되돌린 회수 |
| **충전** | 시스템 단계에서 발행된 크레딧. 개인 지갑에서는 거의 보이지 않습니다 |

**참조** 열이 행의 출처를 말해 줍니다. 세션이거나, *웰컴 크레딧*·*충전 승인* 같은 표시입니다.

사용 행에는 태그 두 가지가 붙습니다.

- **과금 중** — 세션이 아직 실행 중이므로 이 행은 확정된 값이 아닙니다.
- **정산됨** — 세션이 끝났고 더 이상 바뀌지 않습니다.

오래 도는 세션은 초 단위로 쓰지 않고 요약됩니다. 과금 구간마다 한 행이고, 툴팁에 그 안에 묶인 항목
수가 있습니다.

## 찾기

- **검색**은 참조를 찾습니다. 예를 들어 세션 이름.
- **유형 필터**로 배분·사용·환불 등으로 좁힙니다.
- 모든 열이 정렬되고, 필터는 주소창에 담기므로 그대로 공유할 수 있습니다.

## 세션 비용 맞춰 보기

**참조** 열에서 세션을 열거나, 반대로 세션 페이지에서 예상 소모를 보고 종료 뒤 여기의 정산 행과
비교하세요. 두 값은 일치합니다. 세션 페이지도 자체 집계가 아니라 원장에서 계산하기 때문입니다.

숫자가 이상해 보이면 세션 ID(세션 페이지의 복사 버튼)와 시각을 관리자에게 알려 주세요. 원장과
[감사 로그](../admin/audit.md) 모두 전체 흐름을 보관합니다.
