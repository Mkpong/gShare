# 대시보드

로그인 후 첫 화면입니다. 크레딧 잔액, 소진 속도, 활성 세션, 지금 비어 있는 GPU를 한눈에 봅니다.

![사용자 대시보드](/img/screens/user-dashboard.png)

## 네 개의 타일

| 타일 | 내용 |
|---|---|
| **크레딧 잔액** | 개인 지갑의 가용 크레딧과 이번 달 시작 잔액 대비 막대 |
| **소진 속도** | 실행 중인 GPU 세션이 시간당 소비하는 크레딧과, 이 속도로 잔액이 버티는 시간 |
| **활성 세션** | 실행·일시정지·대기 중인 세션 수와 정책의 동시 실행 한도 |
| **실행 중 세션** | 지금 GPU를 쥐고 있는 세션 수 |

**GPU 세션만** 크레딧을 씁니다. CPU 세션과 볼륨은 무료이므로 GPU 세션이 없으면 소진 속도는 0입니다.

## 자원 할당량

**자원 할당량** 패널은 지금 사용 중인 양을 [자원 정책](../admin/resources.md)이 허용하는 한도와
비교합니다 — 세션 수, VRAM과 GPU 코어, 호스트 CPU·메모리·디스크. 막대가 거의 찼다면 새 세션이
*한도 초과*로 거부되는 이유가 그것입니다. **증액 요청** 링크로 관리자가 검토할 쿼터 요청을 보냅니다.

## 모델별 가용성

카드 하나가 여러분이 쓸 수 있는 GPU 모델 하나입니다. VRAM과 지금 빈 조각이 있는지를 보여 줍니다.
[세션 마법사](./sessions-create.md)가 세션이 바로 시작될지 대기열에 들어갈지 추정할 때 쓰는
정보와 같습니다.

## 활성·최근 세션

페이지 하단에는 활성 세션(각각 링크)과 최근 이력, 그리고 소유한 볼륨의 **스토리지** 요약이 있습니다.
모두 [세션](./sessions.md)과 [데이터](./data.md) 페이지로 이어집니다.
