# 대시보드

로그인 후 가장 먼저 표시되는 메인 화면입니다. 크레딧 잔액, 소진 속도, 활성 세션 상태 및 사용 가능한 GPU 자원 현황을 한눈에 확인할 수 있습니다.

![사용자 대시보드](/img/screens/user-dashboard.png)

## 주요 요약 타일

| 타일 | 설명 |
|---|---|
| **크레딧 잔액** | 개인 지갑의 가용 크레딧 및 이번 달 시작 잔액 대비 잔여 비율 표시 |
| **소진 속도** | 실행 중인 GPU 세션의 시간당 크레딧 소모량 및 현재 잔액 기준 예상 사용 가능 시간 |
| **활성 세션** | 전체 활성 세션 수(실행·일시정지·대기) 및 자원 정책상의 동시 실행 한도 |
| **실행 중 세션** | 현재 GPU 자원을 점유하여 실행 중인 세션 수 |

**GPU 세션만** 크레딧이 소모됩니다. CPU 세션 및 스토리지 볼륨은 무료로 제공되므로, 실행 중인 GPU 세션이 없는 경우 소진 속도는 0으로 표시됩니다.

## 자원 할당량

**자원 할당량** 패널에서는 현재 사용 중인 자원량과 [자원 정책](../admin/resources.md)상 허용된 최대 한도(세션 수, VRAM, GPU 코어, 호스트 CPU·메모리·디스크 등)를 비교하여 보여줍니다. 할당량 그래프가 가득 차 있다면 새 세션 생성 시 *한도 초과* 오류로 작업이 거부될 수 있습니다. 자원이 더 필요한 경우 **증액 요청** 링크를 통해 관리자에게 쿼터 증액을 신청할 수 있습니다.

## 모델별 가용성

사용 가능한 GPU 모델별 상태가 개별 카드로 표시됩니다. 각 카드에서는 해당 모델의 VRAM 용량 및 현재 즉시 할당 가능한 여유 자원 존재 여부를 보여줍니다. 이 정보는 [세션 생성 마법사](./sessions-create.md)에서 세션의 즉시 실행 가능 여부 또는 대기열 진입 여부를 추정할 때 동일하게 활용됩니다.

## 대기 중인 세션

현재 대기열에 진입한 세션이 있는 경우 대기 순번, 대기 사유, 경과 시간이 패널에 표시됩니다. [대기열 페이지](./sessions-queue.md)로 이동하지 않고도 대기 상태를 손쉽게 확인할 수 있습니다.

## 활성·최근 세션

페이지 하단에는 활성화된 세션 목록(각 상세 페이지 링크 포함), 최근 작업 이력, 보유한 **스토리지 볼륨** 요약 정보가 제공됩니다. 각 항목을 선택하면 해당 [세션](./sessions.md) 및 [데이터](./data.md) 페이지로 바로 이동합니다.
