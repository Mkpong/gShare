# 데이터와 볼륨

**볼륨**은 세션보다 오래 남는 영구 스토리지입니다. 하나 만들어 `/data` 같은 경로에 마운트하면, 다음
세션이 어느 노드에 뜨든 파일이 그대로 있습니다.

| 페이지 | 내용 |
|---|---|
| [볼륨 만들기](./data-create.md) | 이름, 소유 범위, 종류, 접근 모드, 용량 |
| [세션에서 쓰기](./data-mount.md) | 마운트, 경로, 지금 누가 쓰고 있는지 |
| [볼륨 공유](./data-share.md) | 권한 주기, 읽기전용·읽기/쓰기, 해제 |
| [용량 변경·잠금·삭제](./data-manage.md) | 쿼터 늘리기, 잠금, 안전한 삭제 |

:::tip 볼륨은 무료입니다
크레딧은 GPU 세션 시간에만 부과됩니다. 스토리지를 제한하는 것은 잔액이 아니라
[자원 정책](../admin/resources.md)의 **쿼터**이며, 모든 볼륨에 표시됩니다.
:::

## 볼륨 목록

![볼륨](/img/screens/data.png)

내가 소유한 것과 공유받은 것이 모두 보입니다.

![볼륨 행](/img/screens/data-row.png)

| 열 | 의미 |
|---|---|
| **볼륨** | 이름. 해당되면 **잠김**, **공유됨** 태그가 붙습니다 |
| **범위** | *개인 (내 계정)*, 부서, *전체*, 또는 공유받은 볼륨은 *공유 · 소유자* |
| **접근모드** | 읽기/쓰기(RWX) 또는 읽기전용(ROX). 볼륨 자체의 모드이며, 세션이 마운트할 수 있는 상한입니다 |
| **쿼터** | 사용량 / 할당량과 게이지 |
| **작업** | 공유, 쿼터 변경, 잠금, 삭제 — 공유받은 볼륨은 **공유 해제** |

행을 누르면 펼쳐지며 지금 그 볼륨을 마운트한 세션이 보입니다.
[세션에서 쓰기](./data-mount.md#지금-누가-쓰고-있나)를 참고하세요.

## 범위

| 범위 | 누가 마운트할 수 있나 | 만들 수 있는 사람 |
|---|---|---|
| **개인** | 본인, 그리고 [공유](./data-share.md)한 사람 | 누구나 |
| **부서 공유** | 그 부서의 모든 구성원, 자동으로 | 부서 관리자 |
| **전체** | 로그인한 모든 사용자 | 시스템 관리자 |

## 종류

종류는 용도를 나타내는 라벨입니다. 스토리지 동작이 달라지지는 않습니다.

| 종류 | 용도 |
|---|---|
| **데이터셋** | 학습용 데이터 — 보통 여러 세션이 읽기전용으로 공유 |
| **개인 작업공간** | 세션이 바뀌어도 유지되는 개인 작업 파일 |
| **부서 공유** | 부서원이 함께 읽고 쓰는 공간 |
| **임시 작업공간** | 임시 고속 공간. 정리될 수 있음 |

## 데이터가 있는 곳

볼륨은 사이트가 등록한 스토리지 풀에 있습니다([운영 → 스토리지](../operations/storage.md) 참고).
볼륨은 한 클러스터의 스토리지에 만들어져 거기 머물기 때문에, 멀티 클러스터 설치에서는 그 볼륨을
마운트하는 세션이 그 클러스터에 배치됩니다.
