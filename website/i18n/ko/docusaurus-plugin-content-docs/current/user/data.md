# 데이터와 볼륨

**볼륨**은 세션보다 오래 남는 영구 스토리지입니다. 하나 만들어 `/data` 같은 경로에 마운트하면,
다음 세션이 어느 노드에 뜨든 파일이 그대로 있습니다.

![볼륨](/img/screens/data.png)

:::tip 볼륨은 무료입니다
크레딧은 GPU 세션 시간에만 부과됩니다. 스토리지를 제한하는 것은 잔액이 아니라 관리자 정책이 정한
**쿼터**이며, 각 볼륨에 표시됩니다.
:::

## 볼륨 만들기

**새 볼륨**은 이름, 소유 범위(개인 또는 소속 부서), 용량을 묻습니다. 제출 전에 용량을 정책 한도와
비교합니다. 실제 스토리지는 지연 생성됩니다. 볼륨을 처음 마운트하는 세션이 만들어 냅니다.

## 마운트

볼륨은 [세션 마법사](./sessions-create.md)에서 마운트합니다. 볼륨, 모드(읽기 전용 또는
읽기·쓰기), 마운트 경로를 고릅니다. 세션 상세 페이지에 마운트 목록이 있습니다.

실행 중인 세션이 마운트한 볼륨은 삭제할 수 없습니다. 먼저 세션을 종료하세요. 볼륨의 쿼터는 사용
중에도 늘릴 수 있지만, 저장된 양보다 작게 줄일 수는 없습니다.

## 공유

내 볼륨을 다른 사용자에게 **읽기 전용** 또는 **읽기·쓰기**로 공유합니다. 받은 사람은 허용된
모드로만 마운트할 수 있고, 삭제하거나 재공유할 수 없습니다. 공유 해제는 즉시 적용됩니다.

## 잠금과 삭제

**잠금**은 새 마운트를 막습니다. 데이터를 정리하거나 데이터셋을 넘기기 전에 유용합니다. **삭제**는
볼륨 이름을 입력하도록 요구합니다. 사이트가 정한 유예 기간이 지나면 데이터를 복구할 수 없기
때문입니다.

## 데이터가 있는 곳

볼륨은 사이트가 등록한 스토리지 풀에 저장됩니다([스토리지](../operations/storage.md) 참고). 볼륨은
한 클러스터의 스토리지에 만들어지고 거기 머뭅니다. 사이트가 여러 클러스터를 운영한다면, 그 볼륨을
마운트하는 세션은 그 클러스터에 배치됩니다.
