# 데이터와 볼륨

**볼륨**은 세션 종료 후에도 데이터가 유지되는 영구 스토리지입니다. 볼륨을 생성하여 `/data`와 같은 경로에 마운트하면, 이후 생성되는 세션이 어느 노드에 배치되더라도 동일한 파일 상태가 유지됩니다.

| 페이지 | 내용 |
|---|---|
| [볼륨 만들기](./data-create.md) | 볼륨 이름, 소유 범위, 종류, 접근 모드, 쿼터 설정 |
| [세션에서 쓰기](./data-mount.md) | 세션 마운트 방법, 마운트 경로, 활성 마운트 현황 |
| [볼륨 공유](./data-share.md) | 권한 부여, 접근 모드(읽기 전용/읽기·쓰기), 공유 해제 |
| [용량 변경·잠금·삭제](./data-manage.md) | 쿼터 용량 변경, 신규 마운트 잠금, 안전한 삭제 절차 |

:::tip 볼륨 무료 이용 안내
크레딧은 GPU 세션 실행 시간에 대해서만 과금됩니다. 스토리지 사용량을 제한하는 것은 계정 잔액이 아닌 [자원 정책](../admin/resources.md)상의 **쿼터**이며, 각 볼륨 정보에서 확인할 수 있습니다.
:::

## 볼륨 목록

![볼륨](/img/screens/data.png)

본인이 소유한 볼륨과 공유받은 볼륨 목록이 함께 표시됩니다.

![볼륨 행](/img/screens/data-row.png)

| 열 | 설명 |
|---|---|
| **볼륨** | 볼륨 이름. 상태에 따라 **잠김**, **공유됨** 태그가 함께 표시됩니다 |
| **범위** | *개인 (내 계정)*, 부서 공유, *전체*, 또는 공유받은 볼륨의 경우 *공유 · 소유자* |
| **접근모드** | 읽기/쓰기(RWX) 또는 읽기 전용(ROX). 볼륨 자체의 접근 권한 범위이며, 세션 마운트 시 설정 가능한 최대 권한입니다 |
| **쿼터** | 현재 사용량 / 할당된 쿼터 용량 및 사용량 게이지 |
| **작업** | 공유, 쿼터 변경, 잠금, 삭제 (공유받은 볼륨은 **공유 해제** 표시) |

특정 볼륨 행을 클릭하면 상세 정보가 펼쳐지며 현재 해당 볼륨을 마운트 중인 세션 목록이 표시됩니다. 자세한 내용은 [세션 내 볼륨 사용하기](./data-mount.md#지금-누가-쓰고-있나)를 참고하세요.

## 소유 범위

| 범위 | 마운트 가능 대상 | 생성 권한 |
|---|---|---|
| **개인** | 본인 및 [공유](./data-share.md)받은 사용자 | 모든 사용자 |
| **부서 공유** | 해당 부서 소속 모든 구성원 (자동 공유) | 부서 관리자 |
| **전체** | 시스템에 로그인한 모든 사용자 | 시스템 관리자 |

## 볼륨 종류

볼륨 종류는 용도를 나타내는 분류 라벨이며, 실제 스토리지 동작이나 성능의 차이는 없습니다.

| 종류 | 용도 |
|---|---|
| **데이터셋** | 모델 학습용 데이터셋 (주로 여러 세션에서 읽기 전용으로 공유하여 사용) |
| **개인 작업공간** | 세션 변경 시에도 계속 유지되는 개인 작업 파일 저장소 |
| **부서 공유** | 부서 구성원이 함께 데이터를 읽고 쓰는 공유 저장소 |
| **임시 작업공간** | 일시적인 작업용 고속 공간 (시스템 정책에 의해 정기 정리될 수 있음) |

## 데이터 저장 위치 및 클러스터 배치

볼륨은 시스템에 등록된 스토리지 풀에 위치합니다 ([운영 → 스토리지](../operations/storage.md) 참고). 볼륨은 특정 클러스터의 스토리지 내에 생성되어 유지되므로, 멀티 클러스터 환경의 경우 해당 볼륨을 마운트하는 세션은 볼륨이 존재하는 동일한 클러스터 노드에 자동으로 배치되어 실행됩니다.
