# 용량 변경, 잠금, 삭제

## 쿼터 변경 {#쿼터-변경}

![쿼터 변경](/img/screens/data-quota.png)

**쿼터 변경** 기능을 통해 볼륨의 최대 할당 용량을 증액할 수 있습니다. 대화 상자에 현재 쿼터 및 사용량이 표시되며, 설정할 새 용량은 다음 세 가지 조건을 만족해야 합니다.

- **현재 저장된 데이터 용량 이상:** 데이터 손실 방지를 위해 이미 들어 있는 데이터 용량 이하로 축소할 수 없습니다.
- **사용자 정책의 스토리지 한도 이내:** 보유한 전체 볼륨 용량의 합계 기준입니다.
- **스토리지 서버의 실제 잔여 용량 이내**

변경된 쿼터 용량은 운영 중인 볼륨에 즉시 적용되며, 해당 볼륨을 마운트한 세션은 재시작 없이 새로 할당된 용량을 인식합니다.

스토리지 한도 부족으로 변경이 어려운 경우, 데이터 삭제 전 [마이페이지 → 내 한도](./account-limits.md)에서 쿼터 증액을 신청하세요.

## 잠금

![잠긴 볼륨](/img/screens/data-locked.png)

**잠금** 기능은 볼륨의 *신규* 마운트를 차단합니다. 이미 마운트되어 실행 중인 세션은 영향을 받지 않고 계속 작동합니다.

주로 다음과 같은 상황에서 활용됩니다.

- **볼륨 삭제 전:** 데이터 검토 중 다른 사용자가 신규 세션에서 해당 볼륨을 마운트하지 못하도록 보호합니다.
- **데이터 정리 작업 중:** 작업 중인 세션이 파일에 접근하고 있는 동안 데이터를 이동/수정하여 발생하는 오류를 방지합니다.

잠금 상태는 **잠금 해제**를 통해 원복할 수 있으며, 해제 전까지 볼륨 목록에 **잠김** 태그가 표시됩니다.

## 삭제

![삭제 확인](/img/screens/data-delete-confirm.png)

**삭제** 시 데이터 삭제 위험 안내와 함께 최종 확인 절차를 거칩니다. 볼륨 삭제는 **활성 마운트가 없는 상태**에서만 진행 가능하며, 마운트 중인 세션이 있다면 삭제가 거부됩니다. 이 경우 [상세 정보(펼친 행)](./data-mount.md#지금-누가-쓰고-있나)에서 먼저 종료해야 할 세션을 확인할 수 있습니다.

삭제 완료 시 처리 절차:

1. 볼륨이 목록에서 즉시 제거되며, 해당 용량만큼 스토리지 쿼터가 즉시 환원됩니다.
2. 실제 물리 데이터는 시스템 정책에 따른 유예 기간(기본 24시간) 동안 보존된 후 완전히 회수됩니다.

유예 기간 내에는 관리자를 통한 복구가 가능하지만, 유예 기간이 지나면 영구 삭제되어 복구할 수 없습니다.

:::caution 실행 취소 불가 안내
삭제 확인 창이 데이터 보존의 마지막 단계입니다. 유실 위험이 있는 데이터는 삭제 전 다른 볼륨으로 백업/복사하세요. 볼륨 생성 및 유지에는 별도 비용이 발생하지 않습니다.
:::

## 권장 모범 사례

- **임시 볼륨 주기적 정리:** 프로젝트나 실험이 종료된 임시 볼륨은 삭제하세요. 스토리지 쿼터 부족의 가장 주된 원인입니다.
- **공용 데이터셋 공유 활용:** 공통 데이터셋은 읽기 전용으로 설정한 후 팀원 간 공유하세요. 동일한 100 GiB 데이터셋을 개별 복사하여 사용하는 것보다 자원을 훨씬 효율적으로 관리할 수 있습니다.
- **쿼터 사용량 모니터링:** 볼륨 목록의 **쿼터** 사용량 열을 주기적으로 확인하세요. 사용량이 95%에 도달한 볼륨을 미리 파악하면, 작업 중 `No space left on device` 오류로 프로세스가 중단되는 상황을 방지할 수 있습니다.
