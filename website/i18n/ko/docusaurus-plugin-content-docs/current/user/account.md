# 계정

**마이페이지**는 내 프로필, 내가 지켜야 하는 한도, 그리고 플랫폼이 나에게 알린 기록입니다.

| 페이지 | 내용 |
|---|---|
| [비밀번호](./account-password.md) | 변경, 첫 로그인, 잊었을 때 |
| [내 한도](./account-limits.md) | 적용 중인 자원 정책과 증액 요청 |
| [알림](./account-notifications.md) | 종 아이콘과 알림 내역 |

![계정](/img/screens/account.png)

## 프로필

![프로필](/img/screens/account-profile.png)

| 항목 | |
|---|---|
| **조직** / **부서** | 읽기 전용. 소속은 관리자가 정합니다. 잘못되어 있으면 관리자에게 문의하세요. 누구의 크레딧을 쓰고 어떤 정책이 적용되는지가 여기서 정해집니다 |
| **표시 이름** | 직접 수정합니다. 관리자가 내 세션 옆에서 보는 이름입니다 |
| **이메일** | 로그인 아이디. 관리자만 바꿀 수 있습니다 |
| **사용자 ID** | `usr_…` 식별자와 복사 버튼. 문의할 때 함께 적으세요 |

**저장**은 실제로 바뀐 것이 있을 때만 활성화되고, 비활성일 때는 그 이유를 말해 줍니다.

## 여기 없는 것

- **세션·볼륨·크레딧**은 각자의 화면에 있습니다([세션](./sessions.md), [데이터](./data.md),
  [지갑](./wallet.md)).
- **언어와 테마**는 상단 바에 있고 계정 설정이 아니라 브라우저별 설정입니다.
- **본인 계정 삭제**는 콘솔에서 할 수 없습니다. 관리자가 처리합니다.
