# 계정

![계정](/img/screens/account.png)

계정 페이지는 소속 조직과 부서, 각각에서의 역할을 보여 줍니다. 소속은 관리자가 관리하므로 여기서는
읽기 전용이고, **표시 이름**은 직접 바꿀 수 있습니다.

## 비밀번호 변경

![비밀번호 변경](/img/screens/account-password.png)

**비밀번호 변경**은 현재 비밀번호와 새 비밀번호를 묻습니다. 현재 비밀번호를 잊었다면 관리자가
초기화할 수 있고, 다음 로그인 때 새 비밀번호를 정하게 됩니다.

## 알림

상단 바의 종 아이콘에는 자리를 비운 사이 일어난 일이 모입니다. 대기열에 있던 세션이 시작됨, 유휴로
일시정지되거나 관리자가 종료함, 크레딧 요청 승인, 나에게 공유된 볼륨 등. 각 항목은 해당 대상으로
이어집니다.
