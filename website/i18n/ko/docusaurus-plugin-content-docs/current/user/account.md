# 계정

**마이페이지**에서는 사용자 프로필, 적용 중인 자원 한도, 시스템 알림 내역을 확인하고 관리할 수 있습니다.

| 페이지 | 내용 |
|---|---|
| [비밀번호](./account-password.md) | 비밀번호 변경, 최초 로그인, 재설정 안내 |
| [내 한도](./account-limits.md) | 적용 중인 자원 정책 조회 및 한도 증액 요청 |
| [알림](./account-notifications.md) | 알림 패널(종 아이콘) 및 전체 알림 내역 |

![계정](/img/screens/account.png)

## 프로필

![프로필](/img/screens/account-profile.png)

| 항목 | 설명 |
|---|---|
| **조직** / **부서** | 읽기 전용 항목입니다. 소속 변경은 관리자에게 문의하세요. 소속 정보에 따라 사용 크레딧의 과금 대상과 적용되는 자원 정책이 결정됩니다. |
| **표시 이름** | 사용자가 직접 수정할 수 있습니다. 관리자 콘솔 및 세션 목록 등에 표시되는 이름입니다. |
| **이메일** | 로그인 계정(ID)으로 사용되며, 관리자만 변경할 수 있습니다. |
| **사용자 ID** | 고유 식별자(`usr_…`)와 복사 버튼이 제공됩니다. 시스템 관련 문의 시 해당 ID를 함께 전달해 주세요. |

**저장** 버튼은 실제로 변경된 정보가 있을 때만 활성화되며, 비활성화 상태일 경우 사유가 함께 안내됩니다.

## 기타 기능 안내

- **세션·볼륨·크레딧:** 각 전용 메뉴에서 개별 관리합니다 ([세션](./sessions.md), [데이터](./data.md), [지갑](./wallet.md)).
- **언어 및 테마:** 상단 바에서 설정할 수 있으며, 계정이 아닌 브라우저 로컬 환경별로 저장됩니다.
- **계정 삭제:** 콘솔 내 직접 탈퇴/삭제 기능은 제공되지 않으며, 관리자를 통해 처리해야 합니다.
