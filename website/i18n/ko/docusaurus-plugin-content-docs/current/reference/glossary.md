# 용어집

gShare 플랫폼에서 사용되는 주요 용어 및 개념에 대한 정의입니다.

- **배분 (Allocation)** — 상위 테넌트에서 하위 테넌트로 이동하는 크레딧 할당 흐름 (플랫폼 → 조직 → 부서 → 사용자).
- **클러스터 (Cluster)** — gShare 오퍼레이터가 실행되는 단일 Kubernetes 클러스터 (Data Plane). 제어 플레인(Control Plane)은 다수의 데이터 플레인 클러스터를 통합 관리할 수 있습니다.
- **크레딧 (Credit, C)** — 플랫폼의 기본 과금 정산 단위. GPU 세션은 오퍼링 시간당 단가와 GPU 점유율에 비례하여 크레딧을 차감하며, CPU 전용 세션 및 스토리지 볼륨은 크레딧을 소비하지 않습니다.
- **전용 모드 (Exclusive Mode)** — 단일 GPU 물리 카드를 독점적으로 사용하는 세션 실행 모드 (`nvidia.com/gpu: 1`). HAMi 가상화 컨트롤러를 거치지 않고 전체 카드를 할당받습니다.
- **공유 모드 (Fractional Mode)** — GPU 물리 카드의 VRAM과 컴퓨팅 코어를 일정 비율로 가상 분할하여 사용하는 세션 모드. HAMi 디바이스 플러그인에 의해 제어 및 강제 적용됩니다.
- **부서 (Group / Project)** — 조직 산하의 프로젝트 또는 팀 단위 (API 레벨에서는 `project`로 표기). 구성원, 부서 관리자, 전용 크레딧 풀, 자체 자원 정책을 가질 수 있습니다.
- **크레딧 예약 (Hold)** — GPU 세션 시작 시 실행 유지를 위해 미리 선차감(홀드)되는 크레딧 금액. 세션 실행 중 실시간 소진되며 세션 종료 시 미사용 금액은 지갑으로 자동 환불됩니다.
- **유휴 리퍼 (Idle Reaper)** — 설정된 유휴 시간을 초과하여 작업이 없는 GPU 세션을 자동으로 감지 및 일시 중지시켜 GPU 자원을 회수하는 오퍼레이터 백그라운드 프로세스.
- **노드 풀 (Node Pool)** — 정책에 따라 특정 테넌트에 전용으로 독점 할당할 수 있는 노드들의 집합.
- **점유율 (Occupancy)** — 세션이 할당받은 GPU 물리 자원의 차지 비율로, `max(VRAM 비율, 코어 비율)` 공식으로 산출됩니다.
- **오퍼링 (Offering)** — 특정 GPU 모델을 기반으로 정의된 컴퓨트 카탈로그 상품 (GPU 모델명, 카드의 물리 크기, 시간당 크레딧 단가, 최소 CUDA 요구 버전 등).
- **오퍼레이터 (Operator)** — 각 데이터 플레인 클러스터에서 커스텀 리소스(`GShareSession`)를 파드로 생성/관리하고 상태를 제어 플레인에 보고하는 Go 기반 컨트롤러. 크레딧 차감 및 정산 로직은 수행하지 않습니다.
- **조직 (Organization)** — 멀티테넌시 구조의 최상위 테넌트 단위.
- **일시 중지 / 재개 (Pause / Resume)** — 실행 중인 세션 파드를 삭제하여 GPU 자원 할당과 과금을 중단하고, 볼륨 및 설정 상태를 유지한 채 향후 동일한 상태로 재시작하는 기능.
- **자원 정책 (Resource Policy)** — 동시 실행 세션 수, VRAM/코어 한도, 호스트 자원, 볼륨 쿼터, 최대 실행 시간, 유휴 시간 제한 등을 규정하는 한도 정책 (사용자 → 부서 → 조직 → 전역 순으로 상위 정책이 우선 적용됨).
- **프리셋 (Preset)** — 자주 사용되는 CPU/RAM 및 GPU 가상 분할 티어(XL ½, L ¼, M ⅛, S 1/16 등) 또는 전용 모드 프로필 사전 정의 조합.
- **대기열 (Queue)** — 요구 조건에 맞는 GPU 자원이 부족할 때 세션 요청이 머무르는 대기 공간. 가용 자원 확보 시 우선순위에 따라 순차적으로 승인 및 배치됩니다.
- **세션 (Session)** — 사용자가 작업(JupyterLab, VS Code, SSH 등)을 수행하기 위해 할당받는 컨테이너 환경 (GPU 또는 CPU 기반 파드).
- **스토리지 풀 (Storage Pool)** — 플랫폼에 등록된 백엔드 스토리지 서버 정보 (대상 클러스터, StorageClass, 공유 범위, 최대 가용 용량 등).
- **볼륨 (Volume)** — 사용자가 소유하고 세션에 마운트하여 데이터를 영구 보관하는 스토리지. 별도 비용 없이 무료로 제공되며 자원 정책의 쿼터로 용량이 제한됩니다.
- **지갑 (Wallet)** — 사용자 개인이 보유한 크레딧 계정. 세션 실행에 필요한 크레딧은 해당 세션 소유자의 지갑에서만 차감됩니다.
