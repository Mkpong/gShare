# 용어집

**배분(allocation)** — 계층을 따라 내려가는 크레딧 이동: 플랫폼 → 조직 → 부서 → 사용자.

**클러스터** — gShare 오퍼레이터가 도는 Kubernetes 클러스터 하나. 제어 플레인은 여러 개를 관리할
수 있습니다.

**크레딧(C)** — 과금 단위. GPU 세션은 오퍼링 시간당 단가 × 점유율로 크레딧을 소비하고, 그 외에는
아무것도 소비하지 않습니다.

**전용(exclusive)** — 카드 전체를 차지하는 세션 모드(`nvidia.com/gpu: 1`). HAMi를 거치지 않습니다.

**공유(fractional)** — 카드의 조각(VRAM과 코어 일부)을 차지하는 세션 모드. HAMi가 강제합니다.

**부서(group)** — 조직 안의 팀. API에서는 `project`. 구성원, 관리자, 크레딧 풀, 선택적 정책을
가집니다.

**예약(hold)** — GPU 세션 시작 시 잡히는 크레딧. 실행 중 소비되고 종료 시 환불됩니다.

**유휴 리퍼(idle reaper)** — 정책의 유휴 시간을 넘긴 GPU 세션을 일시정지해 카드를 반환하는
오퍼레이터 루프.

**노드 풀** — 정책이 특정 테넌트에 독점적으로 줄 수 있는 노드 집합.

**점유율(occupancy)** — 세션이 차지한 카드 비율: `max(VRAM 비율, 코어 비율)`.

**오퍼링** — GPU 모델 하나를 상품으로 만든 것: 모델 문자열, 카드 전체 크기, 시간당 단가, 최소 CUDA.

**오퍼레이터** — 각 클러스터에서 `GShareSession` 리소스를 파드로 바꾸고 결과를 보고하는 Go
컨트롤러. 크레딧은 절대 건드리지 않습니다.

**조직** — 테넌시 트리의 꼭대기.

**일시정지 / 재개** — 세션 파드를 내리고(GPU 반환, 과금 중단) 나중에 볼륨과 예약을 유지한 채
되살리는 것.

**정책(자원 정책)** — 한도: 동시 실행 수, VRAM, 코어, 호스트 자원, 볼륨 쿼터, 실행 시간 상한, 유휴
시간. 사용자 → 부서 → 조직 → 전역 순으로 적용.

**프리셋** — 컴퓨트 형태 + GPU 분할 티어(XL ½ … SS 1/32) 또는 전용.

**대기열** — 맞는 카드가 없을 때 세션이 기다리는 곳. 용량이 돌아오면 우선순위 순으로 승인.

**세션** — 사용자의 작업 환경: GPU 또는 CPU 할당과 이미지를 가진 파드 하나.

**스토리지 풀** — 등록된 스토리지 서버: 클러스터, StorageClass, 공유 범위, 용량.

**볼륨** — 사용자가 소유하고 세션에 마운트하는 영구 스토리지. 무료, 쿼터로 제한.

**지갑** — 사용자의 개인 크레딧 잔액. 세션은 소유자의 지갑에서만 과금됩니다.
